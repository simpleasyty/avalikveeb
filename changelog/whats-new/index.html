  • Version 8.0.0

    Simple Tables

    Released on September 9, 2026

    This release introduces Join Tables: combine data from two published Simple Tables on the same Confluence page into one live table, without manually copying rows.

    New: Join Tables

    • Choose Join Simple Tables as the data source in the Simple Table macro. Browse available tables by page position and column names, inspect their previews, and select the matching column from each source.
    • Use an Inner join to show matching rows only, or a Left join to keep every row from the first table and add matching data from the second.
    • Combine tables created with the Simple Table macro or the Simple Table with Body macro. Existing joins can also be used as sources, with safeguards against circular references.
    • Work with the combined result using normal table features, including sorting, filtering, grouping, calculated columns, and exports.

    How to get started

    • Publish at least two Simple Tables on the same page, then insert a Simple Table macro and choose Join Simple Tables.
    • Select the left and right tables, choose their matching columns and join type, then configure the result and publish the page.
    • For example, join a project table with an owner directory using a shared owner ID. Choose a Left join to keep projects even when no owner record matches.

    Before you join

    • Joins read the latest published source configuration. Publish changes to the source tables before expecting them in the joined result; pending page-editor changes are not included.
    • Empty matching values do not match. Match values must have the same type: a number does not match the same digits stored as text. Multiple matching rows produce multiple result rows.
