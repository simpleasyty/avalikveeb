Confluence-Tabellenanleitung

Eine Tabelle in Confluence filtern

Native Tabellen konzentrieren sich auf Bearbeitung, Formatierung und Sortierung. Für interaktive Zeilenfilter benötigen Sie eine Funktion mit Filterunterstützung.

Filterworkflow wählen

Verwenden Sie die Suche für schnelle Textfilterung, Gruppierung für Kategorien und klare Datentypen für konsistente Werte.

Tabelle einrichten

Erstellen oder bearbeiten Sie eine Simple Table, wählen Sie die Quelle, prüfen Sie Spalten, aktivieren Sie Suche und veröffentlichen Sie.

  • Quelle auswählen
  • Überschriften und Typen prüfen
  • Suche aktivieren
  • Repräsentative Werte testen

Mehrdeutige Werte vermeiden

Normalisieren Sie Daten, Wahrheitswerte und Statusbezeichnungen. Konsistente Werte machen Suche, Sortierung und Export vorhersehbar.
