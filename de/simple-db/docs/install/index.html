ERSTE SCHRITTE

Simple DB for Confluence installieren

Installieren Sie Simple DB über den Atlassian Marketplace und öffnen Sie den SQL-Arbeitsbereich.

Vorbereitung

Sie benötigen eine Confluence-Cloud-Site und einen Administrator mit Berechtigung zur App-Installation. Diese Anleitung gilt für Simple DB for Confluence; eine Jira-Installation besitzt eine separate Datenbank.

INSTALLATION STARTEN

App im Marketplace öffnen — Simple DB for Confluence

Installieren Sie Simple DB über den Atlassian Marketplace und öffnen Sie den SQL-Arbeitsbereich.

Im Atlassian Marketplace ansehen

Installation abschließen

  1. 1

    Site auswählen

    Öffnen Sie Simple DB for Confluence im Marketplace, wählen Sie Get it now und anschließend die gewünschte Confluence-Site.

  2. 2

    Prüfen und installieren

    Prüfen Sie die angeforderten Berechtigungen und bestätigen Sie Atlassians Installation. Warten Sie auf die Bestätigung. Die Installation gewährt nicht allen Benutzern Zugriff auf sämtliche Datenbankobjekte.

  3. 3

    Simple DB öffnen

    Öffnen Sie in Confluence Apps → Simple DB. Erstellen Sie Tabellen und Abfragen in SQL Studio oder beginnen Sie mit einer Vorlage. Prüfen Sie vor der Freigabe den Objektzugriff.
