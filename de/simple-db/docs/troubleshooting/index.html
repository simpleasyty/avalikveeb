ADMINISTRATION & FEHLERBEHEBUNG

Abfragen und Seitenmakros beheben

Beheben Sie häufige Probleme mit Katalog, SQL, Zugriff und eingebetteten Ergebnissen.

Objekt fehlt im Browser

Prüfen Sie, ob der Browser auf ein Projekt eingegrenzt ist, und wechseln Sie zu Alle Objekte. Vergewissern Sie sich, dass das Objekt noch existiert und Ihr Konto Leseberechtigung hat.

SQL-Anweisung kann nicht ausgeführt werden

Prüfen Sie den Forge-SQL-MySQL/TiDB-Dialekt, existierende Katalogobjekte und Felder sowie die Beschränkung auf eine Anweisung pro Ausführung. Geben Sie für jeden benannten Parameter einen Wert an.

Makro findet seine Quelle nicht

Bearbeiten Sie das Makro und verbinden Sie es erneut mit einer vorhandenen Tabelle, View oder Abfrage, wenn das referenzierte Objekt umbenannt oder entfernt wurde. Prüfen Sie den Lesezugriff der Seitenleser:innen.

Zeilenbearbeitung ist nicht verfügbar

Bearbeitung erfordert eine beschreibbare Quelle, deren Abfrageherkunft und Primärschlüssel die zugrunde liegende physische Zeile bestimmen. Aggregierte oder anderweitig umgeformte Ergebnisse können schreibgeschützt sein. Gruppierung blendet Zeilenbearbeitung in einer Tabelle ebenfalls aus.

Seite zeigt kein Ergebnis

Führen Sie die Quelle zuerst in SQL Studio aus. Prüfen Sie Filter und Parameterbindungen und vergewissern Sie sich, dass die aktuelle Seitenbetrachtung das Objekt lesen darf. Speichern Sie das Makro nach einer Änderung.

Verwandte Anleitungen

  • SQL Studio verwendenDatenbankobjekte durchsuchen, SQL bearbeiten und Abfrageergebnisse in Simple DB erkunden.
  • Zugriff auf Datenbankobjekte verwaltenSteuern Sie, wer Tabellen, Views, Abfragen und Projekte lesen und ändern darf.
  • Datenbankzuverlässigkeit und SQL-GrenzenErfahren Sie mehr über Atlassians Datenbankisolation, Sicherungen und die gemeinsamen Grenzen einer Installation.
