FELDTYPEN

Confluence-Referenzfelder

v2.1.0+

Confluence-Seite, Bereich oder Person auswählen.

Wann verwenden?

Verwenden Sie Confluence-Referenz, wenn ein Wert auf eine echte Seite, einen Bereich oder eine Person statt auf freien Text verweisen soll.

Feld konfigurieren

Wählen Sie den Referenztyp Seite, Bereich oder Person. Das Formular zeigt die passende Auswahl und speichert die Kennung. Ein kontextbezogener Standardwert kann die aktuelle Seite, den aktuellen Bereich oder die angemeldete Person verwenden.

Beispiel

So kann dieses Feld in einem Schema verwendet werden.

  • KontrollverantwortlicheDie zuständige Confluence-Person
    Person
  • NachweisseiteDie Seite mit dem Nachweis
    Seite
  • Zuständiger BereichDer Bereich des verantwortlichen Teams
    Bereich

Nutzen Sie den aktuellen Bereich als Standardwert. Indexieren Sie Person oder Bereich für Berichtsfilter.

Wichtiges Verhalten

Namen und Seitentitel können sich ändern; gespeichert wird die Entitätskennung. Berichte zeigen zur Laufzeit lesbare Bezeichnungen an.
