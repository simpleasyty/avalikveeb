Native Confluence-Tabellen

Verwenden Sie Simple Table with Body für eine Confluence-Tabelle, die bereits auf der Seite vorhanden ist. Es bietet dieselben Tabellenfunktionen wie Simple Table; nur die Quelle und der Ort der Bearbeitung sind anders.

SIMPLE-TABLE-WITH-BODY-MAKRO

Die Tabelle bearbeiten, das Ergebnis in der Vorschau prüfen

Änderungen an einer nativen Tabelle werden im Confluence-Seiteneditor innerhalb von Simple Table with Body möglicherweise nicht sofort angezeigt. Prüfen Sie die interaktive Tabelle in der Settings-Vorschau oder auf der veröffentlichten Seite; die native Tabelle auf der Seite bleibt die Bearbeitungsquelle.

Vorschau und bekannte Grenzen

  • 1 Erwähnungen bleiben sichtbar und können für die aktuell betrachtende Person hervorgehoben werden, lösen in der Makrotabelle jedoch keine nativen Confluence-Benachrichtigungen aus.
  • 2 Confluence-Datumswerte erscheinen als lokalisierte Datumspills; der zugrunde liegende Wert bleibt für Sortierung, Filter und Berechnungen verfügbar.
  • 3 Table Excerpt / Include funktioniert mit dem Standardmakro Simple Table. Eine in Simple Table with Body verschachtelte Tabelle wird aufgrund aktueller Confluence-Cloud-Einschränkungen nicht unterstützt.

Eine vorhandene Tabelle interaktiv machen

Bearbeiten Sie die Tabelle weiterhin dort, wo sie entstanden ist. Sortierung, Suche, Filter, Gruppierung und die weiteren Funktionen bleiben dieselben wie im Makro Simple Table.

1

Native Tabelle umschließen

Bearbeiten Sie die Confluence-Seite. Erstellen Sie eine native Confluence-Tabelle oder fügen Sie eine ein. Wählen Sie die Tabelle aus und fügen Sie das Makro Simple Table with Body darum ein.

2

Interaktives Verhalten konfigurieren

Wählen Sie die benötigten Optionen für Sortierung, Suche, Filter, Gruppierung, Farben, Datentypen, berechnete Spalten und Aggregationen.

3

Quelle prüfen und veröffentlichen

Im Vorschau-Footer können Sie zwischen Simple Table für die spätere Leseransicht und Confluence-Quelle für die native Tabelle im Makroinhalt wechseln. Die Quellenvorschau ist schreibgeschützt. Bearbeiten Sie die Tabelle im Confluence-Seiteneditor und verwenden Sie anschließend die Makrovorschau oder veröffentlichen Sie die Seite, um das endgültige Verhalten zu prüfen.

TIPP

Wählen Sie das Makro anhand der Quelle, nicht anhand der Funktionen: Simple Table with Body für eine native Tabelle auf dieser Seite, Simple Table für Dateien oder Inhalte aus anderen Seiten.

Beispiel: ein Projektstatus direkt auf der Seite

Ein Team pflegt seinen Status in der Confluence-Tabelle, die bereits auf der Projektseite steht.

Beim Bearbeiten
Die Tabelle bleibt vertraut und direkt im Confluence-Seiteneditor bearbeitbar.
→
Nach dem Veröffentlichen
Leser können dieselben Informationen sortieren, filtern, durchsuchen und gruppieren, ohne dass das Team eine zweite Tabelle pflegt.
