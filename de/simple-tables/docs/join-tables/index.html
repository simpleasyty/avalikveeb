DATEN HINZUFÜGEN

Tabellen verbinden

v8.0.0+Gemeinsame Vorschau ·v8.3.0+

Kombinieren Sie zwei veröffentlichte Simple Tables auf derselben Confluence-Seite zu einer Live-Tabelle.

Eine verbundene Tabelle erstellen

„Simple Tables verknüpfen“ ist unter Daten verfügbar, wenn mindestens zwei andere Tabellen auf dieser Seite veröffentlicht sind.

  1. 1

    Zwei Quelltabellen veröffentlichen

    Fügen Sie zwei Makros vom Typ Simple Table oder Simple Table with Body auf derselben Seite ein und veröffentlichen Sie sie. Eine Verknüpfung kann sich nicht selbst als Quelle verwenden.

  2. 2

    Beide Tabellen wählen

    Fügen Sie ein weiteres Simple Table-Makro ein und wählen Sie unter Daten „Simple Tables verknüpfen“. Suchen Sie die verfügbaren Tabellen, prüfen Sie die Vorschau und wählen Sie erste und zweite Quelle. Die Tabellen werden nach ihrer Position auf der Seite bezeichnet.

  3. 3

    Spalten und Zeilen wählen

    Wählen Sie in jeder Tabelle eine Abgleichspalte. Gleichnamige Spalten werden vorgeschlagen; das Paar bestimmen Sie. Ziehen Sie die Quellkarten, um die Reihenfolge zu ändern. Wählen Sie „Nur passende Zeilen“ oder „Alle Zeilen aus der ersten Tabelle“.

  4. 4

    Prüfen und veröffentlichen

    Prüfen Sie die gemeinsame Vorschau, wählen Sie „Tabelle konfigurieren“, passen Sie die Ergebnisspalten an und veröffentlichen Sie die Seite. Die zweite Abgleichspalte ist zunächst ausgeblendet; unter Spalten können Sie sie anzeigen.

Hinweis

Ist „Simple Tables verknüpfen“ nicht verfügbar, veröffentlichen Sie zuerst zwei andere Simple Tables auf dieser Seite und öffnen Sie den Makroeditor erneut.

Welche Zeilen erscheinen?

Die erste Tabelle bestimmt, welche Zeilen im Ergebnis vorkommen können. Wählen Sie, ob eine Übereinstimmung in beiden Tabellen nötig ist oder auch Zeilen ohne Treffer aus der ersten Tabelle bleiben.

Nur passende Zeilen (INNER)

Eine Zeile erscheint nur, wenn ihr Schlüssel in beiden Tabellen vorkommt.

: A + B

Alle Zeilen aus der ersten Tabelle (LEFT)

Alle Zeilen der ersten Tabelle bleiben erhalten. Ohne Treffer sind die Zellen der zweiten Tabelle leer.

: A + B / A

Beispiel: Bestellungen und Kunden

Verbinden Sie beide Tabellen über die Kunden-ID. Eine Bestellung hat einen passenden Kunden, die andere nicht.

Bestellungen
Bestellung 101 → Kunde A; Bestellung 102 → Kunde B.
Kunden
Kunde A → Acme. Kunde B fehlt in dieser Tabelle.
Nur passende Zeilen (INNER)
Bestellung 101 erscheint mit Acme. Bestellung 102 entfällt.
Alle Zeilen aus der ersten Tabelle (LEFT)
Beide Bestellungen erscheinen. Bei Bestellung 102 bleibt der Kundenname leer.

Abgleich und Aktualisierung

Leere Schlüssel stimmen nicht überein; eine Zahl entspricht nicht einem Text mit denselben Ziffern. Mehrere Treffer erzeugen mehrere Ergebniszeilen. Die Verknüpfung liest veröffentlichte Quelldaten; veröffentlichen Sie Änderungen an den Quellen zuerst. Vorhandene Verknüpfungen können Quellen sein, mit Schutz vor Zyklen und zu tiefer Verschachtelung.
