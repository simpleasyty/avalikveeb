PIVOT-TABELLEN

Pivot-Tabellen

v6.0.0+ENMehrere Felder und Quellvorschau ·v8.6.0+

Fassen Sie Quelldatensätze mit mehreren Zeilenebenen, optionalen Spaltengruppen und einem oder mehreren berechneten Werten zusammen.

Pivot-Tabelle einrichten

Konfigurieren Sie das Simple Table-Makro unter Einstellungen → Pivot. Die Quelldaten bleiben erhalten; die Pivot-Tabelle ändert ihre Darstellung.

  1. 1

    Pivot-Tabelle aktivieren

    Aktivieren Sie Enable pivot table. Für eine vollständige Einrichtung brauchen Sie mindestens ein Feld unter Rows und einen Eintrag unter Values. Columns kann für eine Zusammenfassung nur nach Zeilen leer bleiben.

  2. 2

    Rows und Columns wählen

    Fügen Sie mehrere Felder unter Rows oder Columns hinzu, wenn Sie zusätzliche Ebenen benötigen. Die Reihenfolge bestimmt die Hierarchie. Mit den Schaltflächen können Sie Felder verschieben oder entfernen.

  3. 3

    Values hinzufügen

    Fügen Sie einen oder mehrere Values-Einträge hinzu. Jeder hat ein eigenes Quellfeld und eine Berechnung: Count, Sum, Average, Max oder Min. Bei Count kann das Quellfeld leer bleiben; für die anderen Berechnungen ist ein Zahlenfeld nötig.

  4. 4

    Table options prüfen

    Row totals zeigt Gesamtsummen rechts an, wenn Columns konfiguriert sind. Column totals ergänzt Zwischensummen unter Zeilengruppen und eine Gesamtsumme am Ende. Hide empty columns entfernt Pivot-Wertespalten, deren Ergebnisse alle leer sind.

  5. 5

    Vergleichen und speichern

    Wechseln Sie unten rechts in der Vorschau zwischen Pivot table und Original table, um die Zusammenfassung mit den Quelldatensätzen zu vergleichen. Diese Vorschauauswahl ändert die gespeicherte Pivot-Konfiguration nicht. Speichern Sie das Makro und veröffentlichen Sie die Seite.

Tipp

Beginnen Sie mit einem Rows-Feld und Count. Weitere Ebenen und Berechnungen können Sie später hinzufügen.

Berechnung für jeden Wert wählen

Jeder Values-Eintrag wird für jede Zeilen- und Spaltengruppe getrennt berechnet.

BerechnungWirkungBeispiel
CountZählt Quelldatensätze; das Wertefeld ist optionalTickets pro Projekt zählen
SumAddiert ZahlenwerteArbeitsstunden pro Projekt und Datum
AverageMittelt vorhandene ZahlenwerteDurchschnittliche Bearbeitungszeit pro Team
Min / MaxErmittelt den kleinsten oder größten ZahlenwertNiedrigste und höchste Kosten pro Region

Tabellenoptionen und leere Werte

Diese Einstellungen betreffen das Pivot-Ergebnis, nicht die Quelldaten.

Row totals

Zeigt rechts neben jeder Zeile eine Summe, wenn Spaltengruppen vorhanden sind.

Column totals

Zeigt Zwischensummen unter Zeilengruppen und eine Gesamtsumme am Ende.

Hide empty columns

Blendet eine Pivot-Wertespalte nur aus, wenn alle Ergebnisse leer sind. Null als Zahl (0) ist ein Wert; Spalten mit 0 bleiben sichtbar.

Bei Sum, Average, Min und Max ergibt ein fehlender oder null-Wert ein leeres Ergebnis, wenn kein Zahlenwert zur Zelle beiträgt. Die Zahl 0 bleibt sichtbar und wird mitberechnet.

Beispiel: Projektstunden nach Datum

Angenommen, jeder Datensatz enthält Project, Date und Hours.

Originaltabelle
Jedes Projekt und Datum steht in einem eigenen Datensatz. Einige Hours-Werte sind null, andere 0.
Pivot-Tabelle
Wählen Sie Project für Rows, Date für Columns und Sum of Hours für Values. Leere Ergebnisse bleiben leer, 0 erscheint als 0. Hide empty columns kann Datumswerte entfernen, deren Summen durchweg leer sind; Datumswerte mit Nullen bleiben sichtbar.
