Table Excerpt / Table Excerpt Include

Simple Tables unterstützt Tabellen, die mit Table Excerpt zentral verwaltet und über Table Excerpt Include auf mehreren Confluence-Seiten wiederverwendet werden. Teams behalten damit ihre vorhandene redaktionelle Struktur und ergänzen die eingebundene Tabelle um Suche, Sortierung, Filter, Formatierung und Aggregationen.

TABELLEN WIEDERVERWENDEN

EINMAL PFLEGEN, MEHRFACH VERWENDEN

Wiederverwendbare Confluence-Inhalte werden interaktiv.

Die Quelltabelle bleibt an ihrem etablierten Ort. Jede eingebundene Ansicht kann mit Simple Tables leichter ausgewertet werden, ohne eine zweite Datenkopie zu pflegen.

Zentrale Quelle

Pflegen Sie die Quelltabelle einmal im bestehenden Table-Excerpt-Ablauf.

Mehrere Seiten

Verteilen Sie denselben Tabelleninhalt mit Table Excerpt Include in Confluence.

Interaktive Ansicht

Ergänzen Sie Suche, Sortierung, Filter, Formatierung und Aggregationen für Leser.

TIPP

Empfohlener Aufbau: Verwenden Sie für Table-Excerpt-Abläufe das Standardmakro Simple Table. Simple Table with Body ist für diesen Aufbau derzeit nicht geeignet.

1

Quelltabelle pflegen

Erstellen und aktualisieren Sie die Tabelle auf ihrer Confluence-Quellseite mit Ihrem bestehenden Table-Excerpt-Ablauf.

2

Tabelle wiederverwenden

Binden Sie die Tabelle über Table Excerpt Include auf der Zielseite ein. So bleibt die wiederverwendete Ansicht mit derselben redaktionellen Quelle verbunden.

3

Simple Table hinzufügen

Verwenden Sie das Standardmakro Simple Table mit den gerenderten Tabellendaten und konfigurieren Sie die gewünschten interaktiven Funktionen.

4

Ergebnis veröffentlichen

Veröffentlichen Sie die Seite und prüfen Sie Suche, Sortierung, Filter, Formatierung und Aggregationen in der Leseransicht.

Welches Simple-Tables-Makro passt?

Die Makrowahl hängt davon ab, ob die Tabelle als gerenderter, wiederverwendbarer Inhalt vorliegt oder direkt im Makroinhalt bearbeitet wird.

Simple Table
Empfohlen und unterstützt. Es erweitert die über Table Excerpt Include gerenderten Tabellendaten.
Simple Table with Body
Für diesen Ablauf derzeit nicht unterstützt, da dafür eine Confluence-Tabelle innerhalb des Makroinhalts verschachtelt werden müsste.

Aktuelle Einschränkungen

  • 1 Confluence Cloud erlaubt die benötigte Verschachtelung einer Tabelle in Simple Table with Body derzeit nicht zuverlässig. Verwenden Sie deshalb das Standardmakro Simple Table.
  • 2 Bearbeiten Sie die wiederverwendeten Daten weiterhin in der Table-Excerpt-Quelltabelle. Die eingebundene Simple-Table-Ansicht ist nicht die redaktionelle Quelle.
  • 3 Prüfen Sie das endgültige interaktive Verhalten in der Makrovorschau oder auf der veröffentlichten Seite.

Wann Sie stattdessen eine native Tabelle verwenden

Wenn die Tabelle nur auf einer Seite liegt und direkt dort bearbeitet werden soll, verwenden Sie Simple Table with Body. Dieser Ablauf bewahrt die native Confluence-Tabelle als Bearbeitungsquelle.
