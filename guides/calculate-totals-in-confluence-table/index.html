How to calculate totals in a Confluence table

Simple Tables can calculate summary values in the table footer or within grouped sections, depending on whether you need one overall result or a result per category.

1

Choose the aggregation

Use sum for additive values, average for a representative mean, count for populated records, and minimum or maximum for range boundaries.

2

Configure footer totals

Edit the table, open the column aggregation settings, choose the numeric column and aggregation, and enable the footer result. Verify that the column is configured as a number.

  1. 1 Set the column type
  2. 2 Choose the footer aggregation
  3. 3 Select its display mode
  4. 4 Test empty and zero values
3

Calculate totals by group

Group by a category such as team or region and apply an aggregation to the value column. This produces a result for each group rather than only one table-wide total.

Frequently asked questions

Why is a total not calculated?

The column may be configured as text or may contain values that cannot be interpreted as numbers.

Can Simple Tables calculate an average?

Yes. Average is supported for both documented aggregation and expression workflows.
