Simpleasyty 製品の最新情報

Simple Tables と Simple Metadata で公開した変更と改善に関する情報を確認できます。

  • バージョン 2.1.0

    Simple Metadata 最新

    公開日： 2026年9月24日

    初の一般公開リリース — Atlassian Marketplace で公開

    Simple Metadata 2.1.0 は、Confluence Cloud のページを構造化・検証されたデータに変えます。共通のスキーマを定義し、チームが作業するページで一貫したレコードを収集して、レポートにまとめられます。

    一度定義したスキーマを複数のページで再利用

    型付きフィールド、必須項目、検証、既定値を備えた再利用可能なスキーマを作成できます。テンプレートから始め、スペース、ラベル、グループの権限で利用対象を制御できます。

    作業するページでメタデータを入力

    ページに Simple Metadata マクロを追加し、スキーマに基づくフォームで値を入力できます。通常、コンパクト、カードのレイアウトを選び、フィールドの表示やページ上の履歴タイムラインを設定できます。

    ページのレコードを役立つレポートに

    Simple Metadata Report マクロでエントリを集約し、列の設定やインデックス付きフィールドの型別フィルターを利用できます。閲覧者向けに検索、並べ替え、グループ化、全画面表示、CSV ダウンロードを有効にできます。

    データの変化を追跡

    エントリの履歴とスキーマの改訂を確認し、スキーマとデータをエクスポートできます。スキーマ変更の影響をプレビューしてから、既存のエントリを整合させることができます。

  • バージョン 8.3.0

    Simple Tables 最新

    公開日： 2026年9月21日

    分かりやすいソース設定とライブプレビュー

    Simple Tables 8.3.0 では、公開前のソースデータの確認と結合設定がより分かりやすくなりました。

    結合ウィザードの改善

    統一された見出しと読みやすい文字で、ソースの選択から列の対応付けまで進めます。両方の列を選ぶと、1 つのプレビューに結合結果の最大 5 行が表示され、INNER または LEFT の選択に合わせて更新されます。緑の印は列名と型が同じことを示し、値の一致は保証しません。選択した列を保持したまま、ドラッグまたはキーボードでソースカードを並べ替えられます。「データを編集」で保存済みの結合を再び開けます。

    編集中の CSV と JSON をプレビュー

    入力を少し止めると、エディターの横のテーブルが更新されます。最大 5 行を表示し、カウンターには検出された行と列の合計を表示します。設定にはデータ全体が引き継がれます。空の入力には中立的な表示、読み取れないデータには分かりやすい案内を用意しました。CSV/JSON のファイル内容プレビューも同じレイアウトを使用します。

    統一された操作とイラスト

    共通のイラストでソース選択とプレビューの表示を統一しました。最終設定画面では不要な「戻る」の代わりに「データを編集」を使用します。長い CSV 行はエディター内で横にスクロールし、プレビューやカウンターに重なりません。

  • バージョン 8.2.0

    Simple Tables

    公開日： 2026年9月14日

    Atlassian Store: エンタープライズチームのための保存管理

    Simple Tables に、静的なテーブルの行を Forge に保存する Atlassian Store が加わりました。Confluence 管理者が編集者に許可する保存方式を定め、チームがデータの保存先を選択できます。

    ソースの行を Atlassian に保持

    • ページ本文や添付ファイルと分離して、行を Atlassian がホストする Forge ストレージに保存します。
    • テーブル保存用の Simpleasyty ホストのデータベースを使わず、Atlassian プラットフォームの暗号化とデータ所在地の機能を利用します。
    • Forge のソースデータはページ本文や添付ファイルとしてエクスポートされません。レンダリングされたデータは許可された閲覧者に表示され、有効なテーブルダウンロードも引き続き利用できます。

    サイトのポリシーとテーブルごとの選択

    • アプリ → Simple Tables → 設定で保存方式を管理します。このタブは Confluence 管理者だけに表示されます。
    • ページ内容、添付ファイル、Atlassian Store を有効にし、有効な方式を並べ替えて既定値を設定します。
    • 編集者は保存形式で許可された方式を選択します。既存のテーブルは現在の保存先から読み込み続け、再保存時にポリシーが適用されます。

    機密には Atlassian Store を使用

    • 機密を有効にすると Atlassian Store が自動選択され、ラベルが有効な間は保存方式が固定されます。
    • 管理者が Atlassian Store を有効にしていない場合、トグルは無効になり、管理者への連絡を案内します。
    • ラベルは取り扱いを示すもので、アクセスは Confluence 権限で制御します。保存先を変更しても、以前の添付ファイル、ページ履歴、エクスポート済みのコピーは消去されません。

    Atlassian Store でインコグニート列の値を保護

    • インコグニートを有効にすると、機密ラベルと同様に Atlassian Store が自動選択され、保存先が固定されます。対象の静的テーブルと、管理者による Atlassian Store の有効化が必要です。
    • ページ編集権限をサーバーで確認します。権限のない閲覧者には保護された値が送信されず、列全体がテーブルに表示されません。覆いを重ねる代わりに、データと権限の確認が完了してからテーブルを表示します。
    • 同じフィールドを読み取る列や、その値に依存する計算列も保護されます。全画面表示、フィルター、グループ化、ピボットテーブル、ダウンロード、結合、Rovo は、利用者がアクセスを許可されたデータだけを使用します。
    • 既存のインコグニートテーブルは、Atlassian Store に再保存するとこの保護が適用されます。過去のページバージョン、添付ファイル、エクスポート済みのコピーは変更されません。

    日々の操作をより分かりやすく

    • ページネーションの横にコンパクトなラベルで保存先を表示します。
    • エディターの操作部品とスクロールバーを統一し、スクロール中もテーブルの枠線と角丸を維持します。設定を開く際にはじめにのページが一瞬表示される問題も解消しました。
    • 保存設定とガイドは英語、ドイツ語、日本語で利用できます。

  • バージョン 8.1.0

    Simple Tables

    公開日： 2026年9月11日

    バージョン 8.1.0 では、Simple Tables のテーブル操作を分かりやすくし、設定画面の統一感を高め、使い方ガイドやサポートにアクセスしやすくしました。改善は Simple Table マクロと Simple Table with Body マクロの両方に適用されます。

    見やすく、操作しやすいテーブル

    • 角の丸みと控えめな枠線を取り入れたテーブルテーマに刷新し、検索・フィルターツールバーをコンパクトにしました。
    • 並べ替えの方向と優先順位を明確にし、入れ子のグループを読みやすくしました。日付と列挙型のバッジも統一しました。新しく自動で割り当てる列挙型の色には柔らかい背景色を使用し、保存済みの列挙型の色は保持します。
    • ページ切り替え操作が狭い表示領域に対応し、キーボードフォーカスとスクリーンリーダーの読み上げを改善しました。

    スムーズなテーブル設定

    • 列・表示・書式設定の操作部品を統一し、列一覧をコンパクトにしました。編集者のみに表示される内容の目印も分かりやすくしました。
    • 数式の例をクリックで挿入できます。長い数式プレビューやエラーを省略せずに表示し、日付形式のプレビューを選択欄の横で確認できます。
    • アプリのウェルカムページを簡素化し、両マクロの使い方やドキュメント、サポートに英語・ドイツ語・日本語で直接アクセスできるようにしました。

    修正

    • 表示行数が多い場合もテーブルのスクロール領域内に収まるようにし、丸い角で内容が正しく切り取られるようにしました。全行が収まる表示件数を選んだ後も、表示件数の選択欄を引き続き使用できます。
    • グループ行と合計行に、指定した集計背景色が適用されます。集計背景色を指定していない場合は列の色を継承します。
    • Page Properties の選択欄を改善し、スペースの変更時に選択中のラベルをリセットするようにしました。
    • 設定タブの見出しで不要なスクロールが発生する問題を修正しました。既存のカスタムテーマの色は保持されます。

  • バージョン 8.0.0

    Simple Tables

    公開日： 2026年9月9日

    バージョン 8.0.0 ではテーブル結合が登場しました。同じ Confluence ページで公開されている 2 つの Simple Tables のデータを、行を手作業でコピーせずに 1 つのライブテーブルにまとめられます。

    新機能：テーブルを結合

    • Simple Table マクロのデータソースで Simple Tables を結合を選択します。ページ上の位置や列名からテーブルを探し、プレビューを確認して、各ソースの結合に使う列を選びます。
    • Inner join は一致した行のみを表示します。Left join は最初のテーブルのすべての行を残し、2 つ目のテーブルから一致するデータを追加します。
    • Simple Table マクロまたは Simple Table with Body マクロで作成したテーブルを結合できます。既存の結合もソースとして利用でき、循環参照を防ぐ保護機能があります。
    • 結合結果でも、並べ替え、フィルター、グループ化、計算列、エクスポートなどの通常のテーブル機能を使えます。

    使い始めるには

    • 同じページに少なくとも 2 つの Simple Tables を公開してから、Simple Table マクロを挿入し、Simple Tables を結合を選択します。
    • 左右のテーブル、結合列、結合の種類を選び、結果の表示を設定してページを公開します。
    • 例えば、共通の担当者 ID を使ってプロジェクトテーブルと担当者一覧を結合できます。Left join を選ぶと、一致する担当者がいないプロジェクトも残せます。

    結合前の確認事項

    • 結合は最後に公開されたソース設定を読み取ります。ソーステーブルの変更を結合結果に反映するには、先にその変更を公開してください。ページ編集中の未公開の変更は含まれません。
    • 空の結合値は一致しません。値の型も一致する必要があります。数値と、同じ数字を文字列として保存した値は一致しません。複数の行が一致すると、結果にも複数の行が生成されます。
