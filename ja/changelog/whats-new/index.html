  • バージョン 9.9.0

    Simple Tables最新

    公開日： 2026年10月26日

    Atlassian と同じ配置で、より多くの色を選択

    背景色は 9 列 × 4 行の 36 色から選べ、グリッドの下に「既定」があります。テーブル、列、Enum の背景は同じパレットを使用します。文字色には専用の 2 行のパレットと「白」があります。保存済みの色は保持されます。

    暗い背景でも見出しを読みやすく

    自動設定のテーブル文字色と見出しアイコンは、背景に合わせてコントラストを調整します。並べ替えとグループ化のアイコンは、マウスを重ねたときや操作中も見やすく表示されます。有効なフィルターは各見出しの右上に、ルールと同じ色のコーナーマーカーで表示されます。背景色が似ている場合も、コントラストのある境界線で区別できます。有効な並べ替えは控えめな背景色になり、優先順位の数字が一体で表示されます。明示的に指定した文字色や、保持する Confluence の文字書式の色は維持されます。

    インコグニートを控えめに表示

    列見出しの枠付きアイコンを、小さなコーナーリボンに変更しました。マウスを重ねるかキーボードでフォーカスすると、編集者だけに表示される列であることを確認できます。

  • バージョン 3.4.0

    Simple Metadata最新

    公開日： 2026年10月26日

    公開 Confluence ページでメタデータを閲覧

    Confluence でページへの匿名アクセスがすでに許可されている場合、サインインせずに Simple Metadata マクロと Metadata Report を閲覧できます。Capture マクロでは現在のメタデータを表示し、編集、修復、履歴の操作は提供しません。

    ページの閲覧権限を反映するレポート

    公開レポートには、匿名で閲覧できるソースページと有効なデータ列のみを含め、保存済みのページフィルターと固定フィルターを適用します。検索、並べ替え、グループ化、公開されたフィルター、全画面、CSV は設定で有効な場合に利用できます。編集者のみ、マクロを隠すの設定は引き続き Capture マクロを非表示にし、グループ制限付きスキーマは公開されません。公開閲覧者は管理機能と Ask Rovo を利用できません。

    レポートで Confluence のステータス色を再現

    Confluence Page Properties から取り込んだステータスは、緑、黄、青、赤などの Confluence パレットを使用します。ネイティブの色名を保存した既存スキーマにも適用され、明示的に設定した 16 進数の色は変更しません。明るい色や黄色の背景でもラベルを読みやすく表示します。

    Page Properties の検索結果を分かりやすく

    レポートが見つからない場合は、イラスト付きの案内で選択したスペースと共通ラベルの確認方法を示します。作成直後のレポートは Confluence がインデックス化している場合があります。数分待ってから Find content を再実行してください。

  • バージョン 9.8.0

    Simple Tables

    公開日： 2026年10月21日

    列の型をひと目で確認

    見出しの小さなアイコンで、テキスト、数値、日付、真偽値、列挙型の列を識別できます。新しいテーブルでは既定で有効です。「表示」→「列の型アイコンを表示」で切り替えられます。既存のテーブルでは保存済みの設定が維持されます。

    グループの階層を見分けやすく

    変換の提案を新しい背景色で表示

    おなじみの変換バナーに、紫、ピンク、黄色の柔らかなグラデーションを追加しました。レイアウト、変換プレビュー、提案の設定はこれまでどおり使用できます。

  • バージョン 9.7.0

    Simple Tables

    公開日： 2026年10月20日

    変換前に違いを確認

    ページのバナーから広い移行画面を開きます。「現在のデータ」と Simple Tables のインタラクティブな「プレビュー」を比較し、テーブルやレポートを確認してから、個別または対象の全項目をまとめて変換できます。変換ボタンには公開する対象が表示されます。

    列の情報をより分かりやすく

    ネイティブテーブルと Page Properties Report の両方で、値に応じて、繰り返し出現するテキストの色付きカテゴリ、明示的なパーセント値の進捗バー、数値や通貨の書式、日付、真偽値の表示を利用できます。検出した設定は変換後も引き継がれ、元のコンテンツ、ネイティブ書式、レポートのタイトルリンクも保持されます。

    読み込みと公開の案内を改善

    レポートは操作に応じて読み込み、アニメーション付きの読み込み画面でスキャンの進行状況を確認できます。未公開のページ変更がある場合、変更が1項目だけでも全項目のプレビューと変換を一時停止します。Confluence エディターで公開した後、更新された内容を再確認して選び直してください。 ページ上の別のテーブルがすでに変換されている場合の確認を改善しました。保存結果を確認できない場合は、専用の画面で再読み込みとページ・エディターの確認手順を案内します。

    変換後の可能性を発見

    変換後はテーブルを確認でき、複数の項目を変換した場合はタブで切り替えられます。関連ガイドと Confluence のライブデモから、検索、フィルター、グループ化、計算の使い方を探せます。これらのリンクは新しいタブで開きます。プレビューの検索、並べ替え、フィルターはローカルの表示にのみ適用されます。

    提案を分かりやすく非表示に

    バナーの操作名を「非表示」に変更しました。このページの提案を自分に対して非表示にするか、表示中の種類の提案をサイト全体で自分に対して無効にするかを選べます。既存の個人設定は保持されます。

  • バージョン 9.6.0

    Simple Tables

    公開日： 2026年10月16日

    未公開の変更を公開してから変換

    ページに未公開の変更がある場合は、最後に保存された下書きを確認し、同じタブで Confluence エディターを開きます。他の共同編集者が保存した変更も含め、本文とタイトルの変更をそこで公開してから、テーブルや Page Properties Report の変換内容を再確認できます。

    最新の内容を確認

    確認後に変更が加わった場合は、再度確定する前にプレビューと選択内容が更新されます。対象を個別に変換することも、対象のすべての項目をまとめて変換することもでき、元の位置とページのその他の内容は保持されます。この変換フローは公開済みページが対象で、Live Docs は対象外です。

    結果を確認できない場合の手順を明確化

    公開を確認できない場合は、変換操作の代わりに「ページを再読み込み」を表示します。再試行する前に、ページとエディターの内容を確認してください。Simple Tables が自動で変換を再公開することはありません。

    ライブデモを試す

    「はじめに」の「テーブルの機能を使ってみる」から Confluence デモを開き、既存の操作例を試せます。

    提案の対象と適用範囲を明確に

    ネイティブテーブルの提案は、ヘッダーを含む合計21行以上が対象です。小さいテーブルはバナーの確認や一括変換には表示されません。Page Properties Report の提案は、ヘッダーを含む合計10行以上（ソースページ9件以上）が対象で、小さいレポートはバナーの確認や一括変換には表示されません。テーブル、レポート、両方に合わせたメッセージを表示します。「このページでは不要」から、このページの提案を自分に対して非表示にするか、表示中の種類の提案をサイト全体で無効にするかを選べます。個人設定で非表示ページの提案を再表示しても、通常の表示間隔はリセットされません。

  • バージョン 9.5.0

    Simple Tables

    公開日： 2026年10月15日

    Confluence の作業をよりスムーズに

    既存のテーブルや Page Properties Report をインタラクティブな表示に変えながら、チームのコンテンツと使い慣れたページ編集の流れを保ちます。公開前に変更内容を確認でき、公開後の案内も分かりやすくなりました。

    レポートの内容をひと目で確認

    含まれるページ数と列数を確認できます。レポートの読み込みに合わせて数字が更新されます。

    情報の読みやすさを維持

    太字、斜体、リンクをセル内の元のテキスト部分に保ち、重要な情報を見分けやすく、読みやすく表示します。

    自分のペースで提案を利用

    プレビューを開かずに提案を見送ると、変換の提案は徐々に少なくなります。表示がある最初の日は最大5回、次の日は最大2回、その次は1回です。その後は週1回の提案が2回あり、以降は30日に1回になります。利用しない期間に段階が飛ぶことはありません。「今日は表示しない」で提案を最低24時間完全に非表示にでき、タブも残りません。予定された待機期間がそれより長い場合は、その期間が優先されます。個人設定で提案を無効にすることもできます。

  • バージョン 9.2.0

    Simple Tables

    公開日： 2026年10月14日

    ページ上で Page Properties Report を変換

    対象のネイティブ Page Properties Report を確認し、ライブの Simple Table マクロに変換できます。各レポートのソーススペース、ラベル、対応するプロパティ列が引き継がれます。設定を維持できないレポートはネイティブのまま残ります。

    1 つのライブレポートで複数のラベルを使用

    1 つのスペースで Page Properties のラベルを 1 つ以上選択できます。いずれかの選択ラベルに一致するページが対象となり、複数のラベルに一致しても同じページは 1 回だけ表示されます。既存の単一ラベルのテーブルも引き続き使用できます。見出し行と値の行を 1 行ずつ持つ横方向のプロパティテーブルも正しく読み取れます。

    未変換のコンテンツを 1 つのバナーに表示

    ネイティブテーブルと Page Properties Report は、同じページに複数のレポートがある場合も 1 つのバナーにまとまります。個別に確認・変換することも、選択した置き換えを 1 つの新しいページ版としてまとめて公開することもできます。変換済みマクロが提案を表示させることはありません。テーブルとレポートの提案は、サイト設定と個人設定でそれぞれ個別に管理できます。

    変換前後の確認を強化

    公開前にページ版、未公開の変更、ソースデータを確認し、公開後は公開ページとエディターの下書きを検証します。読み取れないレポートや不完全なレポートは変換しません。結合セル、画像、対応していない入れ子のコンテンツがあるテーブルは提案の対象外です。

    製品分析のプライバシー情報を明確化

    プライバシーポリシーでは、仮名化された分析識別子、サイトとインストールの情報、管理者による制御、イベントデータの 36 か月の保持設定を説明しています。テーブルの値やメタデータの入力値は、製品イベントのプロパティに含まれません。

    Simple Tables

    公開日： 2026年10月12日

    ページ上の Confluence ネイティブテーブルを変換

    ページの編集権限がある人は、公開済みページの上部に表示される変換の提案を確認できます。行と列をプレビューし、ページ上のネイティブテーブルを 1 つ、またはすべて変換できます。変換後も Simple Table with Body マクロ内で内容を編集でき、行、セル内容、元の書式が保たれます。選択したテーブルは元の位置で置き換わり、新しいページ版が 1 つ公開されます。

    未公開のページ変更を保護

    下書きに未公開の変更がある場合や変換前にテーブルが変更された場合、Simple Tables は変換を停止し、元のテーブルを残します。公開済みページと内容が同じ古い下書きは変換を妨げません。

    Simple Tables

    公開日： 2026年10月9日

    柔軟なピボットテーブルで分析

    Rows、Columns、Values に複数のフィールドを追加できます。フィールド順が行と列の階層を決め、Columns は空欄にもできます。各値には Count、Sum、Average、Max、Min を個別に設定します。

    合計と空の列を制御

    行と列の合計は別々に切り替えられます。Hide empty columns はすべての結果が空のピボット値列だけを隠します。null や欠損した数値は空欄になり、0 は表示され計算にも含まれます。

    ピボットと元データを比較

    Settings のプレビュー下部で Pivot table と Original table を切り替えても、保存済みのピボット設定は変わりません。ピボットの操作部はコンパクトになり、プレビューは独立してスクロールできます。ページの編集時と表示時でもピボット結果が一貫して表示されます。

    Page Properties の対象範囲を確認

    Settings のプレビュー下部に、Page Properties テーブルの保存済みスペースとラベルが表示され、元データの対象範囲を確認しやすくなりました。

    Simple Tables

    公開日： 2026年9月29日

    Confluence のライブテーブルを 1 つの画面で設定

    Page Properties と Confluence Content では、検索、列、プレビューを同時に表示します。基本検索または CQL で対象を探し、フィールドと型を選び、選択したフィールドをドラッグして並べ替え、最初の 10 行を確認できます。Page Properties のスキャンでは進行状況を表示し、停止もできます。Confluence のステータス色はプレビューでも読みやすく表示されます。

    必要なときに最新のデータを取得

    Confluence の直近の結果は、サイト、アカウント、ページ、データソースごとに分けて、同じブラウザー内で最大 5 分間再利用されます。公開テーブルと設定プレビューは新しい結果を共有します。検索とフィルターの横にある更新アイコンを選ぶと現在のデータを取得でき、カーソルを合わせると最後に正常更新した日時が表示されます。取得中はアイコンに進行状況が表示され、更新に失敗しても公開テーブルには以前の行が残ります。

    ガイド付きで計算列を作成

    ガイド付きエディターで、列、数値、テキストを演算、関数、条件と組み合わせます。詳細モードでは数式を直接入力できます。有効な計算は追加前にテーブルのプレビューへ下書きとして表示されます。表示される見出しから列を選択でき、見出しを変更しても参照は維持されます。存在しない参照や循環参照には分かりやすいエラーを表示します。計算は Incognito の保護を守りながら集計、結合、ピボットでも使用できます。

    大きなテーブルを移動しやすく

    グループ化したテーブルのページネーションは最上位グループを数え、展開した子行をまとめて表示します。大きなグループでは子行を 50 行ずつ追加表示でき、計算とエクスポートには引き続きすべての行が使われます。グループ化していないテーブルでは 1 ページ最大 500 行を選べます。設定の既定ページサイズはマクロに保存され、各閲覧者はそのマクロ用の選択をブラウザー内に保持できます。

    設定とフィルターを分かりやすく

    新しいテーブルは既定でフィルターモードで開き、明示的に保存された検索モードは維持されます。有効なモードも見分けやすくなりました。変更した設定を閉じるときは、編集を続けるか変更を破棄するかを選べます。保存済みフィルターの設定も見つけやすくなりました。

    データソースの選択とファイルの確認をより簡単に

    貼り付け、Page Properties、Confluence Content、または利用可能な結合設定は 1 回のクリックで開きます。ローカルファイルやページの添付ファイルを選ぶと、読み込み後、テーブル設定の前に専用のテーブルプレビューが表示されます。Incognito と Confidential は対象の静的データ専用のため、ライブ連携には表示されません。

    より多くのカテゴリを Enum として検出

    値が十分な頻度で繰り返される場合、異なる値が最大 25 個ある列を自動的に Enum として検出できるようになりました。パレットを使い切ると色は再利用されますが、色数によって Enum の値の数は制限されません。

    Simple Tables

    公開日： 2026年9月14日

    Atlassian Store: エンタープライズチームのための保存管理

    Simple Tables に、静的なテーブルの行を Forge に保存する Atlassian Store が加わりました。Confluence 管理者が編集者に許可する保存方式を定め、チームがデータの保存先を選択できます。

    ソースの行を Atlassian に保持

    • ページ本文や添付ファイルと分離して、行を Atlassian がホストする Forge ストレージに保存します。
    • テーブル保存用の Simpleasyty ホストのデータベースを使わず、Atlassian プラットフォームの暗号化とデータ所在地の機能を利用します。
    • Forge のソースデータはページ本文や添付ファイルとしてエクスポートされません。レンダリングされたデータは許可された閲覧者に表示され、有効なテーブルダウンロードも引き続き利用できます。

    サイトのポリシーとテーブルごとの選択

    • アプリ → Simple Tables → 設定で保存方式を管理します。このタブは Confluence 管理者だけに表示されます。
    • ページ内容、添付ファイル、Atlassian Store を有効にし、有効な方式を並べ替えて既定値を設定します。
    • 編集者は保存形式で許可された方式を選択します。既存のテーブルは現在の保存先から読み込み続け、再保存時にポリシーが適用されます。

    機密には Atlassian Store を使用

    • 機密を有効にすると Atlassian Store が自動選択され、ラベルが有効な間は保存方式が固定されます。
    • 管理者が Atlassian Store を有効にしていない場合、トグルは無効になり、管理者への連絡を案内します。
    • ラベルは取り扱いを示すもので、アクセスは Confluence 権限で制御します。保存先を変更しても、以前の添付ファイル、ページ履歴、エクスポート済みのコピーは消去されません。

    Atlassian Store でインコグニート列の値を保護

    • インコグニートを有効にすると、機密ラベルと同様に Atlassian Store が自動選択され、保存先が固定されます。対象の静的テーブルと、管理者による Atlassian Store の有効化が必要です。
    • ページ編集権限をサーバーで確認します。権限のない閲覧者には保護された値が送信されず、列全体がテーブルに表示されません。覆いを重ねる代わりに、データと権限の確認が完了してからテーブルを表示します。
    • 同じフィールドを読み取る列や、その値に依存する計算列も保護されます。全画面表示、フィルター、グループ化、ピボットテーブル、ダウンロード、結合、Rovo は、利用者がアクセスを許可されたデータだけを使用します。
    • 既存のインコグニートテーブルは、Atlassian Store に再保存するとこの保護が適用されます。過去のページバージョン、添付ファイル、エクスポート済みのコピーは変更されません。

    日々の操作をより分かりやすく

    • ページネーションの横にコンパクトなラベルで保存先を表示します。
    • エディターの操作部品とスクロールバーを統一し、スクロール中もテーブルの枠線と角丸を維持します。設定を開く際にはじめにのページが一瞬表示される問題も解消しました。
    • 保存設定とガイドは英語、ドイツ語、日本語で利用できます。

    Simple Tables

    公開日： 2026年9月9日

    バージョン 8.0.0 ではテーブル結合が登場しました。同じ Confluence ページで公開されている 2 つの Simple Tables のデータを、行を手作業でコピーせずに 1 つのライブテーブルにまとめられます。

    新機能：テーブルを結合

    • Simple Table マクロのデータソースで Simple Tables を結合を選択します。ページ上の位置や列名からテーブルを探し、プレビューを確認して、各ソースの結合に使う列を選びます。
    • Inner join は一致した行のみを表示します。Left join は最初のテーブルのすべての行を残し、2 つ目のテーブルから一致するデータを追加します。
    • Simple Table マクロまたは Simple Table with Body マクロで作成したテーブルを結合できます。既存の結合もソースとして利用でき、循環参照を防ぐ保護機能があります。
    • 結合結果でも、並べ替え、フィルター、グループ化、計算列、エクスポートなどの通常のテーブル機能を使えます。

    使い始めるには

    • 同じページに少なくとも 2 つの Simple Tables を公開してから、Simple Table マクロを挿入し、Simple Tables を結合を選択します。
    • 左右のテーブル、結合列、結合の種類を選び、結果の表示を設定してページを公開します。
    • 例えば、共通の担当者 ID を使ってプロジェクトテーブルと担当者一覧を結合できます。Left join を選ぶと、一致する担当者がいないプロジェクトも残せます。

    結合前の確認事項

    • 結合は最後に公開されたソース設定を読み取ります。ソーステーブルの変更を結合結果に反映するには、先にその変更を公開してください。ページ編集中の未公開の変更は含まれません。
    • 空の結合値は一致しません。値の型も一致する必要があります。数値と、同じ数字を文字列として保存した値は一致しません。複数の行が一致すると、結果にも複数の行が生成されます。
