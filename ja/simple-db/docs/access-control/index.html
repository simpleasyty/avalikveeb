アクセスとセキュリティ

データベースオブジェクトへのアクセスを管理

テーブル、ビュー、クエリ、プロジェクトの読み取りと変更を管理します。

アプリへのアクセス

Simple DB はサイトのアプリ アクセスゲートを使って、アプリを開けるユーザーを制御します。管理者はアクセス制限と利用を許可されたユーザーやグループを確認できます。

オブジェクト単位のアクセス

データベースオブジェクトには個別のアクセスルールがあります。必要なユーザーやグループに読み取りまたは書き込み権限を付与し、マクロやプロジェクトを広く共有する際に確認してください。

公開前にアクセスを確認

現在の閲覧者が参照オブジェクトの権限を持つ場合にのみ、マクロはソースを読み取れます。予定する閲覧者のアカウントで埋め込み結果をテストし、必要な権限だけを付与してください。

プロジェクトは整理、ポリシーは許可

プロジェクトは関連オブジェクトを見つけやすくします。テーブル、ビュー、クエリごとのアクセスルールを置き換えるものではありません。

関連ガイド

  • プロジェクトとオブジェクトアクセス関連するデータベースオブジェクトをまとめ、SQL Studio ブラウザーを絞り込みます。
  • データベースの信頼性と SQL の制限Atlassian が管理するデータベースの分離、バックアップ、インストールごとの上限を確認します。
