ページマクロとビュー

列の表示とフィールド形式を設定する

SQL の列型を変更せず、テキスト、数値、日付、真偽値、ステータス、Atlassian 参照を表示します。

表示設定とスキーマを分ける

結果ビューの設定で Columns を選びます。順序、表示用 Header、読み取り専用 Data field、可視性を設定し、最初の行のプレビューで確認します。これは表示の設定です。物理 SQL 列は Properties → Columns で管理します。

テキスト、数値、日付

テキストは単一行・複数行表示と同じタブ・新しいタブへのリンクに対応します。数値には Plain、Decimal、Compact、Percent、Currency、精度、任意の進捗バーがあります。日付には Date、Date & time、ロケール、ISO8601、カスタム形式があります。SQL に保存された値自体は変更しません。

真偽値と Enum/Status

真偽値フィールドは対応する true/false 値を表示します。Enum は Pill、Status、Colored text、Simple、Raw と値ごとの色を設定できます。物理 SQL ENUM に由来する選択肢はスキーマで固定されます。ビューで色を変え、許可値の集合を変える場合は SQL 定義を変更します。

Atlassian 参照と権限

Confluence のカタログは、対応するリゾルバーが利用可能なユーザー、ページ、スペース参照を解決できます。必要な形式で値を保存し、想定する閲覧者で確認してください。参照の表示は Confluence コンテンツの権限を付与しません。フィールドの非表示はアクセス制御ではありません。

Enum の値を検出して色を選ぶ

列を Enum に変更すると、読み込み済みプレビューから最大25個の異なる値を検出します。既存の設定では Use loaded values で不足する選択肢を追加し、独自の色と説明を保持できます。カラーピッカーは Simple Tables と同じ36色を提供します。未読み込みのデータベース行を検索したり、SQL ENUM 定義を変更したりする操作ではありません。

関連ガイド

  • テーブルのプロパティを確認・変更するGeneral、Columns、Constraints、Indexes、DDL、Restrictions と必要な権限を確認します。
  • 再利用する結果ビューを作成・管理するプレビュー、表示、列を設定し、テーブルやクエリに便利な表示を保存します。
