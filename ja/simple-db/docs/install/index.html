はじめに

Simple DB for Confluence をインストール

Atlassian Marketplace から Simple DB をインストールし、SQL ワークスペースを開きます。

始める前に

Confluence Cloud サイトとアプリをインストールできる管理者が必要です。このガイドは Simple DB for Confluence が対象です。Jira のインストールは別のデータベースを使用します。

インストールを開始

Marketplace でアプリを開く — Simple DB for Confluence

Atlassian Marketplace から Simple DB をインストールし、SQL ワークスペースを開きます。

Atlassian Marketplace で見る

インストールを完了する

  1. 1

    サイトを選択

    Marketplace で Simple DB for Confluence を開き、Get it now と対象の Confluence サイトを選択します。

  2. 2

    確認してインストール

    要求される権限を確認し、Atlassian のインストール手順を承認します。完了を待ってください。インストールしても、すべてのユーザーに全オブジェクトへのアクセス権が付与されるわけではありません。

  3. 3

    Simple DB を開く

    Confluence で Apps → Simple DB を開きます。SQL Studio でテーブルやクエリを作成するか、テンプレートから始めます。結果を共有する前にオブジェクトのアクセス権を確認してください。
