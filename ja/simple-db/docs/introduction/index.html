はじめに

Simple DB for Confluence の概要

Atlassian Forge にリレーショナルデータを作成し、SQL の結果を Confluence コンテンツとして活用します。

Runs on Atlassian

Simple DB は Simpleasyty が開発し、Atlassian Forge が処理とストレージを提供します。SQL テーブルと行を Simpleasyty 独自のデータベースに保存する必要はありません。インストール前に Marketplace のリストとデータの取り扱いを確認してください。

  • Atlassian 上で動作 — Simple DBSimple DB の Atlassian Forge 上での処理と保存、およびインストール前の確認事項について説明します。→

リレーショナルデータが役立つ理由

型付きの列にレコードを保存し、SQL クエリを再利用してチームのページに結果を表示できます。テーブル、ビュー、保存済みクエリが継続的な作業に共通の構造を与えます。

データの取得元

SQL Studio でテーブルや行を作成するか、ガイド付きビルダーやソリューションテンプレートを使用します。クエリは現在のアプリインストールのデータベースを参照します。

互換性のある .sql スクリプトの読み込み、SQL テキストや結果の CSV 出力、長いジョブのバックグラウンド実行も利用できます。

テーブルの結果には型別フィルター、グループ集計、列の書式、行の編集、再利用可能な結果ビューもあります。カード、メトリクス、ガイド付き SQL ビルダーはサイトで有効な機能によって利用できます。

データの保存先

リレーショナルテーブルと行は Forge SQL、補助的なアプリレコードは Forge KVS に保存されます。各 Confluence インストールには独立したデータベースがあります。ページマクロはページ本文にデータベースのコピーを保存せず、オブジェクトを参照します。

  • データ所在地Simple DB のデータ保存先と、Forge のデータ所在地と Confluence サイトの関係を確認します。→
  • Forge での保存Simple DB のどのデータが Forge SQL と Forge KVS に保存されるかを確認します。→

何をしますか？

  • Simple DB for Confluence をインストールAtlassian Marketplace から Simple DB をインストールし、SQL ワークスペースを開きます。
  • クイックスタートテーブルを作成し、クエリを実行して結果を Confluence ページに追加します。
  • Atlassian 上で動作 — Simple DBSimple DB の Atlassian Forge 上での処理と保存、およびインストール前の確認事項について説明します。
  • SQL Studio を使うデータベースオブジェクトを参照し、SQL を編集してクエリ結果を確認します。
  • テンプレートを使うTemplates ギャラリーから初期データモデルとサンプル SQL をインストールします。
  • SQL とデータのインポート・エクスポート互換性のある SQL スクリプトを Studio に読み込み、SQL テキストやクエリ結果を出力します。
  • バックグラウンド処理長い SQL 実行やテンプレート処理をバックグラウンドで進めながら作業を続けます。
