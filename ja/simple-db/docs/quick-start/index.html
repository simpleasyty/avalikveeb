はじめに

クイックスタート

テーブルを作成し、クエリを実行して結果を Confluence ページに追加します。

始める前に

アプリをインストールし、ワークスペースを開けることと、マクロを追加する Confluence ページを編集できることを確認してください。

出発点に合うマクロを選ぶ

Simple DB マクロ

テーブル、ビュー、保存済みクエリの結果セットを表示する場合は Simple DB マクロを使用します。ソースと必要なパラメーターを指定し、テーブル、カード、メトリクスの表示を設定してプレビューを確認します。

  • テーブル表示を設定する使い慣れたテーブル操作で SQL の結果を検索、絞り込み、グループ化、書式設定、編集します。→
  • カードビューを設定クエリ行を読みやすいカードまたはリストとして Confluence ページに表示します。→
  • メトリクスを設定クエリ結果を目標と比較できる KPI タイルに変換します。→

Simple DB value マクロ

文章中に単一のスカラー値を表示する場合は Simple DB value を使用します。インラインマクロでソースと値を設定します。複数の行やインタラクティブな結果表示が必要な場合は通常の Simple DB マクロを使用してください。

  • 値をインライン表示クエリまたはテーブルの単一値を Confluence ページ本文に表示します。→

実用上の違い

Simple DB マクロは結果セットを、Simple DB value はページの文章中に単一の値を表示します。どちらも現在の Confluence インストールのオブジェクトを参照します。

最初のワークフローを試す

1. Studio を開く

Atlassian 管理者に、利用する製品向けの Simple DB のインストールを依頼します。Confluence または Jira の Apps から Simple DB を開き、Studio に移動します。アカウントにはアプリへのアクセス権が必要です。

New SQL editor を選ぶか、タブバーの + を使います。以下の SQL 文を Run で 1 つずつ実行してください。例では help_tasks という新しいテーブルを作成します。同名のテーブルがある場合は、すべての例で別の名前を使用してください。

2. テーブルを作成する

この SQL 文を実行すると 3 列が作成されます。id 列は主キーで、各行に異なる ID が必要です。

CREATE TABLE help_tasks (
  id INT NOT NULL PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  status VARCHAR(20) NOT NULL
);

3. 行を追加する

この SQL 文を 1 回実行し、サンプルのタスクを追加します。主キーは一意である必要があるため、同じ ID で再実行するとエラーになります。

INSERT INTO help_tasks (id, title, status)
VALUES (1, 'Review onboarding', 'Open');

4. データを読み出す

このクエリを実行します。結果には、ID が 1、タイトルが Review onboarding、ステータスが Open の 1 行が表示されます。

SELECT id, title, status
FROM help_tasks
WHERE status = 'Open'
ORDER BY id
LIMIT 20;

5. クエリを保存する

エディターの保存操作から SELECT 文を名前付きクエリとして保存します。ブラウザーの Queries に表示され、再度開いたり、埋め込みのソースとして選んだりできます。

結果を共有する前に、保存済みクエリと読み取り対象データへのアクセス権を確認します。ページや課題に結果を表示する方法は公開ガイドを参照してください。

  • SQL Studio を使うデータベースオブジェクトを参照し、SQL を編集してクエリ結果を確認します。→
  • テンプレートを使うTemplates ギャラリーから初期データモデルとサンプル SQL をインストールします。→
  • Confluence に Simple DB マクロを追加クエリ結果または単一のライブ値を Confluence ページに埋め込みます。→
  • 値をインライン表示クエリまたはテーブルの単一値を Confluence ページ本文に表示します。→
