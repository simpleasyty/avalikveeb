信頼とセキュリティ

Atlassian 上で動作 — Simple DB

Simple DB の Atlassian Forge 上での処理と保存、およびインストール前の確認事項について説明します。

Runs on Atlassian とは？

Runs on Atlassian（ROA）は、Atlassian Marketplace にある対象の Forge アプリに付与される信頼性バッジです。処理とストレージが Atlassian のインフラ内にあり、データ所在地と外部送信の管理に関する Atlassian の要件を満たすアプリを見分けやすくします。

アプリデータの保存先と流れを、より簡単に理解できます。

チームでの導入を検討する際に、次の 3 つの範囲を確認してください。

  • Atlassian がホストForge がアプリの処理とホスト型ストレージを提供します。主要なデータに Simpleasyty 独自のデータベースは必要ありません。→
  • データ所在地対象の Forge データは対応する Atlassian の所在地管理に従います。Atlassian 管理画面でサイトとアプリの状態を確認してください。→
  • 外部送信の管理宣言された外部利用状況分析と組織の制御は、データベースの保存とは別に確認してください。→

このバッジが実際に意味すること

Simple DB は Atlassian Forge 上で動作します。Forge SQL にリレーショナルデータを、Forge KVS に補助的なレコードを保存します。開発とサポートは Simpleasyty、ホスティング基盤は Atlassian が提供します。バッジは Atlassian の推奨を意味せず、権限とプライバシーの確認に代わるものではありません。

利用状況分析とデータベースの内容

アプリは Forge のデータ保存とは別に、限定的な外部利用状況分析を宣言しています。組織の要件に合わせてプライバシーポリシーと権限を確認してください。Forge 上での動作は、すべてのネットワーク通信が無効であることを意味しません。
