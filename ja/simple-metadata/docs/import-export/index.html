インポートとエクスポート

Simple Metadata パッケージでスキーマとエントリーを移動します。

ワークフロー

1

エクスポート

スキーマ、エントリー、履歴は、それぞれの管理ビューから JSON または YAML の Simple Metadata パッケージとしてエクスポートできます。

2

インポート

現在インポートで作成されるのはスキーマのみです。パッケージにエントリーが含まれる場合は無視されるものとしてプレビューされ、ページ固有のデータが別のサイトに誤って配置されることを防ぎます。

パッケージに含まれるもの

スキーマ、エントリー、エントリー履歴は、それぞれの管理ビューから JSON または YAML の Simple Metadata パッケージとしてエクスポートできます。エクスポートはレビュー、ワークフロー定義のバックアップ、サイト間の制御された移行に使えます。

インポートは変更前にパッケージをプレビューします。作成されるのはスキーマのみで、エントリーと履歴はソース Confluence サイトのページに紐付くため無視されます。

ワークフローを安全に移す

スキーマをインポートし、対象サイトでフィールド、既定値、権限を確認してから、対象ページに新しい Capture マクロを配置します。インポートによって元サイトのページ固有エビデンスやマクロが再作成されることはありません。

ヒント

インポートで作成されるのは意図的にスキーマのみです。ページ固有のエントリーは、別のサイトに配置する代わりに無視されるものとしてプレビューされます。

結果

Simple Metadata パッケージでスキーマとエントリーを移動します。
