Page Properties をインポート

v3.3.0+

ガイド付きのインポートで、既存の Confluence Page Properties を Simple Metadata に取り込みます。

始める前に

以下の手順を進める前に、必要な条件を確認してください。

  • Simple Metadata のアプリ管理機能へのアクセス。
  • Page Properties を含む Confluence ページと、取り込むページの閲覧権限。入力マクロを追加する場合は、ページの編集権限も必要です。
  1. 1

    インポートウィザードを開く

    Simple Metadata アプリで Schemas → Import を開き、ソースとして Page Properties を選びます。Discover に進みます。

  2. 2

    取り込むページを選ぶ

    既存の Page Properties Reports を検索し、取り込むレポートを選択します。適切なレポートがない場合は、スペースとラベルで指定する方法を使用します。検索には Confluence のページ権限が適用されます。

  3. 3

    提案されたスキーマを確認する

    Preview schema では、一致するページのサンプルからフィールドが提案されます。定義とフィールドの対応を確認し、レポートのフィルターに使うフィールドのインデックス設定も確認してから進みます。プレビューはサンプルです。バックグラウンドのインポートでは、表示されたページだけでなく、一致するすべてのページを処理します。

  4. 4

    確定して進捗を確認する

    選択内容を確認し、必要に応じてインポート先のページに Simple Metadata の入力マクロを追加します。インポートを開始し、ウィザードまたは Processes で進捗を確認します。選択したレポート、またはスペースとラベルの組み合わせごとに、独立したスキーマとバックグラウンドジョブが作成されます。ウィザードを閉じても処理は続きます。

  5. 5

    取り込んだデータでレポートを作る

    取り込んだスキーマとメタデータを確認し、Confluence ページに Simple Metadata Report マクロを追加します。新しいスキーマと列を選び、インデックス付きフィールドのフィルターを設定します。複数の選択済みソースレポートに含まれるページには、新しいスキーマごとに個別のメタデータが作成されます。

元のページへの影響

元の Page Properties と Page Properties Report のマクロは残ります。インポートはページのデータを Simple Metadata にコピーする操作で、継続的な同期は設定されません。入力マクロの追加は任意です。パッケージファイルのインポートは別の操作で、スキーマのみを取り込みます。

ページがスキップされた場合や処理が失敗した場合

Processes で進捗とジョブの詳細を確認します。閲覧権限がない、Page Properties を解析できない、再試行時にメタデータがすでに存在するなどの理由でページがスキップされる場合があります。既存のメタデータは上書きされず、スキップされます。入力マクロを追加できない場合は編集権限を確認してください。メタデータの取り込みとマクロの配置は別々の処理です。
