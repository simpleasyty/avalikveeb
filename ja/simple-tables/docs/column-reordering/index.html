列を設定

列の並べ替え

v2.2+EN

Simple Table マクロで列の順序を変え、閲覧者にとって重要な情報を先頭に置きます。

列の順序を変える

エディターで列をドラッグし、保存前に結果を確認します。

  1. 1

    Columns を開く

    Simple Table マクロを編集し、Columns タブを選びます。

  2. 2

    列をドラッグする

    列名の横にある 6 つの点のアイコンをつかみ、一覧の上下に移動します。

  3. 3

    確認して保存する

    プレビューで左右の順序を確認してからマクロを保存します。

変更前と変更後

あるチームは、内部 ID より先にステータスと担当者を見たいと考えています。

変更前

  1. 1顧客 ID
  2. 2メモ
  3. 3ステータス
  4. 4次回確認日
  5. 5担当者

変更後

  1. 1ステータス
  2. 2次回確認日
  3. 3担当者
  4. 4顧客 ID
  5. 5メモ

列が多い場合

開ける列設定パネルは一度に 1 つです。開いたパネルをスクロールしても、ドラッグハンドルを含む列の行が上部に表示されます。編集中の列を見失わずに移動できます。

変わるもの

列の並べ替えで変わるのは、このテーブルの列の配置です。元の行、値、データ型、計算は変わりません。

Confluence のネイティブテーブルを使った Simple Table with Body では、ページ編集中の列順が変わって見えない場合があります。編集画面には Confluence の元のテーブルが表示されるためです。保存した順序は Simple Tables のプレビューか公開ページで確認してください。
