Confluence テーブル

Confluence ネイティブテーブル

v3.0.0+EN操作可能なアクション項目 ·v6.9.0+ENページ上での変換 ·v9.1.0+下書きの公開ガイド ·v9.6.0+

Simple Table with Body は、ページ上にすでにある Confluence テーブルに使用します。Simple Table と同じテーブル機能を提供し、異なるのはソースと編集する場所だけです。

実際の動作を見る

英語の公開デモ · ログイン不要

ライブデモを試す (新しいタブで開きます)すべてのデモ → (新しいタブで開きます)

既存のテーブルをインタラクティブにする

テーブルは作成した場所で引き続き編集できます。並べ替え、検索、フィルター、グループ化などの機能は Simple Table マクロと同じです。

  1. 1

    ネイティブテーブルを囲む

    Confluence ページを編集します。 Confluence ネイティブテーブルを作成するか貼り付けます。 テーブルを選択し、その周囲に Simple Table with Body マクロを追加します。

  2. 2

    インタラクティブな動作を設定

    並べ替え、検索、フィルターなどを選びます。「ネイティブの表示を維持」で Confluence の書式を引き継ぎ、「最初の列をフィールド名として使用」で 2 列のテーブルを項目と値の組として表示します。 同じセル内でも、太字や斜体などの書式は元のテキスト部分ごとに維持されます。

  3. 3

    ソースを確認して公開

    プレビューのフッターでは、閲覧者向けの Simple Table と、マクロ本文に保存されたネイティブテーブルを確認する Confluence ソースを切り替えられます。

補足

ソースプレビューは読み取り専用です。Confluence ページエディターでテーブルを編集し、マクロプレビューまたは公開ページで最終的な動作を確認してください。

ページ上の既存テーブルを変換する

公開済みページに、まだマクロ内に入っていない、ヘッダーを含む合計21行以上の対象 Confluence ネイティブテーブルがある場合、Simple Tables はページ上部に変換の提案を再表示できます。すでに Simple Table with Body 内にあるテーブルは、提案の対象になりません。

  1. 1

    変換内容を確認

    「変換をプレビュー」を選びます。対象テーブルを個別に確認するか、「すべて確認」で表示された項目をすべて確認します。Page Properties Report もある場合は、1 つのバナーにテーブルとレポートがまとめて表示されます。未公開の変更がある場合は、変換を確定する前に以下の手順で公開してください。

  2. 2

    変換を確定

    選択したテーブルは元の位置で Simple Table with Body マクロに置き換わります。行、列、セル、ネイティブ書式はマクロ本文に保持されます。複数のテーブル、またはテーブルとレポートの混在した選択も、まとめて 1 つの新しいページ版として公開されます。

  3. 3

    テーブルの編集を続ける

    変換後はページエディターでマクロ本文のネイティブテーブルを編集したり、マクロ設定でインタラクティブな機能を設定したりできます。

補足

公開済みページと内容が同じ下書きは、変換を妨げません。確認後にページや保存済みの下書きが変わった場合は、プレビューを作り直すため、再確認と再確定が必要です。確認をキャンセルしても何も公開されません。

ヒント: ページ編集権限、個人設定、対象コンテンツを確認してから提案を表示し、エディター内では非表示になります。「このページでは不要」から2つの範囲を選べます。「このページでは提案しない」は、このページの変換の提案を自分に対して非表示にします。「今後は提案しない」は、現在表示されている種類の提案を、この Confluence サイト全体で自分に対して無効にします。他のユーザーには影響しません。アプリ → Simple Tables → 個人設定 で非表示ページの提案を再表示したり、種類ごとの設定を変更したりできます。再表示しても他の個人設定と通常の表示間隔は維持されます。管理者は Simple Tables → Simple Table 設定 で2つのサイト設定を個別に管理できます。ネイティブテーブルはヘッダーを含む合計21行以上が対象で、Page Properties Report はヘッダーを含む合計10行以上（ソースページ9件以上）が対象です。どちらも以下の表示間隔を共有します。待機期間中は非表示ですが、開いている確認画面は引き続き利用できます。

ページに未公開の変更がある場合の手順

プレビューは、未公開のタイトルや本文の変更を含む、最後に保存された下書きを使用します。開いているエディターの内容が Confluence に保存されるまで待ってください。変更を公開するまでは変換できません。

  1. 1

    Confluence エディターで公開する

    「エディターを開いて公開」を選びます。同じタブでエディターが開きます。他の共同編集者が保存した変更も含め、未公開の変更をすべて確認してから、Confluence の「公開」または「更新」を押してください。

  2. 2

    最新の内容を確認して変換する

    公開後、エディターを閉じた状態のページを確認します。バナーが最初の提案を表示している場合は、もう一度「変換をプレビュー」を選びます。確認画面は最新の内容を読み込み、以前の選択をリセットします。テーブルやレポートを選び直し、更新されたプレビューを確認してから確定してください。未公開の変更がまだ表示される場合は、「公開しました — 再確認」を選びます。

ページ版はそれぞれ別に作成されます

未公開の変更の公開でページ版が1つ作成され、変換でさらに1つ作成されます。内容が異なる下書きがなければ、変換で作成される新しいページ版は1つだけです。

結果を確認できない場合

保存への応答が届かない場合や保存された結果を確認できない場合は、変換操作の代わりに「ページを再読み込み」を表示します。再読み込みしてページの変換後の内容を確認し、次に「編集」を選んで同じ内容があることを確認してください。Simple Tables が自動で公開を繰り返すことはありません。

公開済みページが対象です。 このバナーのフローは公開済みの Confluence ページが対象です。Live Docs は変換の提案から除外されます。

提案の表示頻度は徐々に少なくなります

変換のプレビューを開かずに提案を見送ると、提案の表示頻度は徐々に少なくなります。この間隔は、このサイトの全ページでアカウントごとに共有されます。

  1. 1

    表示がある最初の日

    最初の提案から24時間以内に最大5回表示されます。

  2. 2

    次に表示がある日

    次の表示がある24時間の期間内に最大2回表示されます。

  3. 3

    表示がある3日目

    1回表示され、その後7日間は表示されません。

  4. 4

    週1回の提案が2回

    7日後に1回、その7日後にもう1回表示されます。

  5. 5

    月1回の提案

    2回目の週次の提案から30日間待機します。その後は最大30日に1回表示されます。

表示のタイミングを選べます

利用しない期間に段階が飛ぶことはありません。次の期間は、新たな提案が表示されたときに始まります。プレビューを開くと、表示回数の残りをリセットしたり待機期間を短くしたりせず、現在の段階を1サイクル維持します。「このページでは不要」で、そのページの提案を自分に対して非表示にできます。再表示しても表示間隔はリセットされません。以前保存した一時停止は期限まで有効です。待機期間中はバナーもタブも表示されません。

バナーが表示されるテーブルの条件

未変換のテーブルだけが対象

Simple Table マクロだけがあるページには、変換の提案は表示されません。ネイティブテーブルが残っている場合や、後から新しく追加した場合は、そのテーブルが提案の対象になります。移行済みマクロに対して変換や修復は提案されません。

ページの最上位にある対応テーブル

自動提案は、通常の行とセルを持つ、ヘッダーを含む合計21行以上のページ最上位の独立したテーブルが対象です。小さいテーブルも手動でマクロ内に挿入できますが、バナーの確認や一括変換には表示されません。レイアウトや別のマクロの中のテーブル、結合セル、画像、入れ子のテーブル、対応していないマクロ内容は提案されません。

テーブルとレポートを 1 つのバナーに表示

対象のネイティブテーブルと Page Properties Report は同じ確認画面に表示されます。個別に変換することも、対象をすべてまとめて変換することもできます。各レポートのスペースとラベルはそれぞれ維持され、対象をすべて変換すると提案は表示されなくなります。

例: ページ上のプロジェクトステータス

チームはプロジェクトページの Confluence ネイティブテーブルを Simple Table with Body で囲みます。

ネイティブテーブル
列: 作業、担当者、ステータス。行: デザイン → Maya → 順調、テスト → Sam → ブロック中。
編集時
作業やステータスは引き続き Confluence テーブルで直接変更します。
公開後
閲覧者は「ブロック中」で絞り込んだり、担当者で並べ替えたりできます。データ元は同じテーブルです。

2 列の詳細テーブル

Confluence テーブルは、ページ、プロジェクト、リクエスト、レコードの説明に使用されることがあります。この形式では、最初の列がフィールドラベル、2 番目の列が値です。

このようなテーブルでは、表示の「最初の列をフィールド名として使用」を有効にします。これにより、日付、ステータス、数値、テキストをフィールドごとに適切に扱えます。

2 列の詳細テーブルの例
担当Product Operations
ステータス順調
レビュー日四半期ごと

Action Items と権限

Action Items は公開後も操作できます。チェック状態、メンション、期限、リンク、インライン書式が維持されます。

ページ編集権限を持つ閲覧者は公開テーブルから直接タスクを完了または再開でき、それ以外の閲覧者にはアクセシブルな読み取り専用チェックボックスが表示されます。期限超過の日付は赤で表示され、同じ表示見出しが複数あっても各タスクは独立したままです。

テーブルを編集し、結果はプレビューで確認する

ネイティブテーブルの変更は、Confluence ページエディター内の Simple Table with Body ではすぐに表示されない場合があります。インタラクティブなテーブルは Settings プレビューまたは公開ページで確認してください。ページ上のネイティブテーブルが編集元のままです。

プレビューと既知の制限

プレビューまたは公開後のページで操作できるテーブルを確認してください。一部の Confluence コンテンツは表示方法が異なり、入れ子にできない場合があります。

メンション

メンションは表示用に維持され、現在の閲覧者と一致する場合は強調表示されますが、マクロのテーブルから Confluence ネイティブの通知は送信されません。

日付

Confluence の日付はローカライズされた日付ピルで表示され、元の値は並べ替え、フィルター、計算に引き続き使用できます。

入れ子

Table Excerpt / Include は標準の Simple Table マクロで使用します。現在の Confluence Cloud の制限により、Simple Table with Body 内にテーブルをネストする方法はサポートされません。
