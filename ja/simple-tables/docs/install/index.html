Simple Tables をインストール

Confluence 管理者が Atlassian Marketplace から対象サイトに Simple Tables をインストールします。権限を確認し、正しいサイトを選択してからインストールを承認してください。

はじめに

前提条件

Simple Tables をインストールするには、Confluence Cloud インスタンスの管理者権限が必要です。これらの権限を持つアカウントでログインしていることを確認してください。

インストールを開始

Marketplace で Simple Tables を開く

Atlassian Marketplace を開き、Get it now を選んで、対象の Confluence サイトへのインストールを完了します。

Atlassian Marketplace で見る

インストールを完了する

Marketplace のリストを開いたら、Atlassian の標準インストールを完了します。

1

アプリ一覧の 今すぐ入手 ボタンをクリックします。

2

複数の Atlassian Cloud インスタンスがある場合は、インストール先を選択します。

3

要求される権限を確認し、承認してインストール をクリックします。

ヒント

通常、インストールは 1 分以内に完了します。完了すると確認メッセージが表示されます。
