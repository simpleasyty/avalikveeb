Jira 課題近日公開

Jira の検索結果を Confluence のライブでインタラクティブなテーブルにします。統合は実装済みですが、Simple Tables が無料の Marketplace アプリとして提供されている間は利用可能にできません。

SIMPLE TABLE マクロ

チームのページの文脈で JIRA の作業を確認。

JQL で設定する、ライブの Jira ビュー。

テーブルに含める作業を選び、読み手に必要な Jira フィールドを選択し、現在の課題データに接続した表示を維持します。

JQL で検索

プロジェクト、担当者、課題タイプ、ステータス、テキストのシンプルなフィルターを使うか、完全な JQL クエリを記述します。

役立つフィールドを選択

予定されているソースには、キー、要約、ステータス、優先度、担当者、報告者、プロジェクト、課題タイプ、日付が含まれます。

Jira のアクセス権を尊重

各閲覧者には、すでにアクセスを許可されている Jira の作業項目だけが表示されます。

まだ利用できない理由

Jira 統合は、Atlassian Administration を通じた接続フローを含め、Simple Tables 内で完成しています。ただし Atlassian Marketplace のルールでは、この製品間 Jira 接続を提供する前にアプリを有料にする必要があります。Simple Tables は現在無料のため、統合はまだお客様に提供されません。

統合で利用できるようになること

  • シンプルな Jira 検索から始め、より正確なロジックが必要な場合は高度な JQL に切り替えます。
  • 1〜1,000 件の課題を返し、公開するテーブルに必要な列を選びます。
  • Atlassian Administration で管理者が管理する Jira 接続を使用します。Jira API トークンや別の Simple Tables アプリは必要ありません。
  • 保存した JQL をテーブル読み込み時に再実行し、各閲覧者がアクセスできる現在の Jira 課題を表示します。
