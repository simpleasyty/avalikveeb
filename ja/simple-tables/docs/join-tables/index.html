テーブルの結合

v8.0.0+結合結果のプレビュー ·v8.3.0+結合結果の段階的な読み込み ·v8.5.0+

同じ Confluence ページで公開済みの 2 つの Simple Tables を、1 つのライブテーブルにまとめます。

結合テーブルを作成する

このページに別の公開済みテーブルが 2 つ以上あると、データタブで「Simple Tables を結合」を選べます。

  1. 1

    元のテーブルを 2 つ公開する

    同じページに Simple Table または Simple Table with Body マクロを 2 つ追加して公開します。結合自身をソースにすることはできません。

  2. 2

    両方のテーブルを選ぶ

    別の Simple Table マクロを追加し、データタブで「Simple Tables を結合」を選びます。利用可能なテーブルを検索してプレビューを確認し、1 つ目と 2 つ目のソースを選びます。テーブルはページ上の位置で識別されます。

  3. 3

    列と行を選ぶ

    各テーブルで照合列を選びます。同名の列が提案されますが、組み合わせは自分で決めます。ソースカードをドラッグすると順序を変えられます。「一致する行のみ」または「最初のテーブルのすべての行」を選びます。

  4. 4

    確認して公開する

    結合結果のプレビューを確認し、「テーブルを設定」で列を調整してページを公開します。2 つ目の照合列は初期状態で非表示ですが、列の設定で表示できます。

補足

「Simple Tables を結合」が使えない場合は、このページに別の Simple Tables を 2 つ以上公開してからマクロエディターを開き直してください。

表示される行

結果に表示できる行は、最初のテーブルを基準に決まります。両方のテーブルで一致する行だけを表示するか、一致しない最初のテーブルの行も残すかを選びます。

一致する行のみ (INNER)

キーが両方のテーブルにある行だけを表示します。

: A + B

最初のテーブルのすべての行 (LEFT)

最初のテーブルの行をすべて残します。一致しない場合、2 つ目のテーブルのセルは空になります。

: A + B / A

例: 注文と顧客

顧客 ID を使って 2 つのテーブルを結合します。顧客が一致する注文と、一致しない注文があります。

注文
注文 101 → 顧客 A、注文 102 → 顧客 B。
顧客
顧客 A → Acme。顧客 B はこのテーブルにありません。
一致する行のみ (INNER)
注文 101 は Acme とともに表示されます。注文 102 は表示されません。
最初のテーブルのすべての行 (LEFT)
両方の注文が表示されます。注文 102 の顧客名は空欄になります。

照合と更新

空のキーは一致せず、数字と同じ桁の文字列も一致しません。複数の一致は複数行になります。結合は公開済みのソースデータを読むため、先に元のテーブルの変更を公開してください。既存の結合もソースにできますが、循環や深すぎる入れ子は防止されます。大きな結果は 500 行ずつ表示され、暫定的な行数と読み込み状況を確認できます。結果の上限は 10,000 行です。
