ピボットテーブル

ピボットテーブル

v6.0.0+EN複数フィールドと元データのプレビュー ·v8.6.0+

複数の行階層、任意の列グループ、1 つ以上の集計値で元データを要約します。

ピボットテーブルを設定する

Simple Table マクロの Settings → Pivot で設定します。元のレコードは保持され、ピボットは表示方法を変更します。

  1. 1

    ピボットを有効にする

    Enable pivot table をオンにします。設定を完成させるには、Rows に 1 つ以上のフィールド、Values に 1 つ以上の項目が必要です。行だけで要約する場合、Columns は空欄のままで構いません。

  2. 2

    Rows と Columns を選ぶ

    詳細な階層が必要な場合は、Rows または Columns に複数のフィールドを追加します。フィールドの順序が階層を決めます。移動ボタンで順序を変え、削除ボタンで取り除けます。

  3. 3

    Values を追加する

    Values を 1 つ以上追加します。各項目で元フィールドと Count、Sum、Average、Max、Min のいずれかを選びます。Count では元フィールドを空欄にできます。ほかの計算には数値フィールドが必要です。

  4. 4

    Table options を確認する

    Columns を設定した場合、Row totals は各行の右に合計を追加します。Column totals は行グループの下と表の末尾に集計行を追加します。Hide empty columns は結果がすべて空のピボット値列を非表示にします。

  5. 5

    比較して保存する

    プレビュー右下の Pivot table と Original table を切り替え、要約と元のレコードを比較します。このプレビューの切り替えは保存済みのピボット設定を変更しません。マクロを保存し、ページを公開します。

ヒント

まず Rows フィールドを 1 つと Count を設定し、必要に応じて階層や計算を追加します。

値ごとに集計方法を選ぶ

Values の各項目は、行と列のグループごとに個別に計算されます。

集計動作例
Count元のレコード数を数える。値フィールドは任意プロジェクトごとのチケット数
Sum数値を合計するプロジェクトと日付ごとの作業時間
Average利用可能な数値の平均を求めるチームごとの平均対応時間
Min / Max最小または最大の数値を求める地域ごとの最小・最大コスト

テーブルのオプションと空の値

これらの設定は元データではなくピボットの結果に適用されます。

Row totals

列グループがある場合、各行の右端に合計を表示します。

Column totals

行グループの下に小計を、表の末尾に総計を表示します。

Hide empty columns

すべての結果が空のピボット値列だけを非表示にします。0 は値なので、0 を含む列は表示されます。

Sum、Average、Min、Max では、数値がそのセルに 1 つもない場合、null や欠損値の結果は空になります。0 はそのまま表示され、計算にも含まれます。

例: 日付別のプロジェクト作業時間

各レコードに Project、Date、Hours があるとします。

元のテーブル
プロジェクトと日付の組み合わせごとにレコードがあります。Hours には null と 0 が含まれます。
ピボットテーブル
Rows に Project、Columns に Date、Values に Sum of Hours を設定します。空の結果は空欄のまま、0 は 0 と表示されます。Hide empty columns ではすべての合計が空の日付列を隠せますが、0 を含む列は残ります。
