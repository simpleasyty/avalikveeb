In progress

  • Pivot Table (v1)

    In progress ETA: Q4 2025
    • #analysis
    • #aggregation

    Create pivot tables by selecting row/column axes and an aggregation (SUM, AVG, COUNT, MODE).

    Full details
    First version includes Row field, Column field, and Value aggregation. Supports SUM, AVG, COUNT, MODE with CSV export and compact view.

Released

  • Global Filters Bar

    Released v. 7.3.0
    • #ux
    • #filters
    • #search

    Global filter bar (Slack-style) above the table to combine conditions quickly.

    Full details
    Search and composable filters with removable chips, type-aware operators, AND/OR groups, and saved reader views.

  • Page Properties Integration

    Released v. 7.3.0
    • #integration
    • #confluence
    • #performance

    Build live reports directly from Page Properties macros on labelled Confluence pages.

    Full details
    Select one space and label, choose discovered fields, and keep selected property values current without using Page Properties Report.

  • Enum v2

    Released v. 4.0.0
    • #formatting
    • #data-types

    New Enum type with four display styles (Pills, Simple, Colored text, Raw) and auto-detection when >80% rows repeat values.

    Full details
    Supports custom options even if not present in source data. Useful for categorizing statuses and priorities.

  • Formatting panel redesign

    Released v. 4.0.0
    • #formatting
    • #ux
    • #ui

    Redesigned Formatting panel with unified Layout & Density and new table height controls.

    Full details
    New single density combo and height settings: Small, Medium, Large, Full content.

  • New aggregation: Mode

    Released v. 4.0.0
    • #aggregation
    • #grouping
    • #statistics

    Added Mode aggregation in Grouping and Footer aggregations.

    Full details
    Displays the most frequent value in a column, useful for categorical fields.

  • Localized date rendering

    Released v. 3.5.0
    • #dates
    • #localization

    Render dates with locale formatting (e.g. European format in German instances).

    Full details
    Respects Confluence language settings when displaying dates.

  • Confluence-style date formats

    Released v. 3.3.0
    • #dates
    • #localization

    Support for Confluence-style date formats (ISO8601 and localized).

    Full details
    Improves international date display and reliable sorting.

  • Excel import & export

    Released v. 3.0.0
    • #excel
    • #io

    Support for importing and exporting Excel (XLS) files.

    Full details
    Shipped in a major release along with UI and performance improvements.

  • Grouping by any column

    Released v. 3.0.0
    • #grouping
    • #aggregation

    Group rows by any column with aggregations in headers and footers.

    Full details
    Helps summarize large tables into compact, structured views.

  • Native Confluence tables (double-macro)

    Released v. 3.0.0
    • #confluence
    • #native-tables

    Support for native Confluence tables via a double-macro approach.

    Full details
    Editing the native table reflects changes inside Simple Tables automatically.

  • CSV & JSON import

    Released v. 2.2
    • #io
    • #csv
    • #json

    Import data from CSV/JSON (paste, upload, or Confluence attachments).

    Full details
    Core feature since version 2.2 enabling simple data ingestion.
