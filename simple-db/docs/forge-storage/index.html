STORAGE & PRIVACY

Storage in Forge

See which Simple DB data uses Forge SQL and Forge KVS.

Relational data in Forge SQL

Forge SQL holds the installation’s relational tables and rows. SQL Studio and page macros access the same installation’s database. The SQL engine uses the MySQL/TiDB dialect; review the SQL limits guide before designing large workloads.

Supporting records in Forge KVS

Supporting app records and background-job data use Forge KVS. There is no per-table choice between page content, attachments and Forge storage. A macro refers to its source object; it is not a portable database backup.

Access and exports

Review object access before sharing a page or query. A CSV export contains query results, not a complete restorable database. Keep exported files within your organization’s approved storage.
