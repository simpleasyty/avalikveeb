IMPORT

Import a JSON or YAML schema package

v2.1.0+

Create schemas from an exported Simple Metadata package.

Before you begin

Check these requirements before following the steps below.

  • A Simple Metadata package file in .json, .yaml or .yml format.
  1. 1

    Open Import

    In Simple Metadata, open Schemas and select Import. Choose Schema package as the source.

  2. 2

    Choose and check the file

    Download the example JSON if you need a valid starting file. Upload your JSON or YAML package, then review the preview of schemas to create and any names that will be changed to avoid a conflict.

  3. 3

    Import the schemas

    Select Import, then review the created schemas and their access rules before using them on pages.

  4. 4

    What the file import includes

    This workflow imports schema definitions only. Page metadata and history in the package are skipped; no page values or capture macros are created.
