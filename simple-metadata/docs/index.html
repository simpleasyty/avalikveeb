Simple Metadata documentation

Start with the schema-to-report workflow, then explore schemas, capture, reports and administration.

SIMPLE METADATA

Before you begin

  • Access to a Confluence site with Simple Metadata installed.
1

The workflow

An administrator defines a schema in the Simple Metadata global page. Authors use the Simple Metadata macro to save one structured entry on each relevant page. A Simple Metadata Report then brings entries for that schema together.

2

Try it with a small record

Start with a status, owner and next review date. Mark only the fields that a report must filter as indexed, then use the same schema on two or more pages to make the report meaningful.

Result

You know where schemas, capture entries and reports fit in one workflow.
