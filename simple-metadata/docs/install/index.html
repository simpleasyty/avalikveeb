Before you begin

You need a Confluence Cloud site and a site administrator who can install apps. Confirm the destination site and review the requested permissions.

START THE INSTALLATION

Open the app in Marketplace — Simple Metadata

Install the app from Atlassian Marketplace and open it in Confluence.

View on Atlassian Marketplace

Complete the installation

  1. 1

    Choose your site

    Open the Marketplace listing, select Get it now and choose the Confluence site where your team works. Ask your administrator if installation is restricted.

  2. 2

    Review and install

    Review Atlassian’s installation screen and permissions, then confirm. Wait for the installation confirmation before opening the app.

  3. 3

    Open Simple Metadata

    In Confluence, open Apps → Simple Metadata. Start with a schema, then use the Simple Metadata and Simple Metadata Report macros to capture values and report across pages.
