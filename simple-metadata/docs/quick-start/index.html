Quick start

Create a schema, capture metadata on a page, and publish a report.

GET STARTED

1

Create a schema

Open the Simple Metadata global page, choose Create schema and start from a template or a blank schema. Add the fields authors should fill in and save.

2

Add the capture macro

Insert the Simple Metadata macro on a Confluence page, select an eligible schema, then publish the page.

3

Save an entry

Authors fill in the generated form and save the page-level entry. The form validates values against the schema.

4

Publish a report

Insert Metadata Report, select the same schema, choose columns, and optionally expose indexed filters to viewers.

Before you begin

You need permission to create or manage schemas and a Confluence page where the schema is eligible. If you intend to filter a report, mark those fields indexed while designing the schema; adding indexing later may require reconciliation of saved entries.

A useful first report

Start with page title, space, last modified and the two or three schema fields reviewers use most. Keep filters deliberate, then enable only the viewer controls—search, filters, sorting, grouping, full screen or CSV—that help the published audience.

TIP

Start with a small schema and index only the fields you genuinely need to filter in reports.
