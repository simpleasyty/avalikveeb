Build a Metadata Report

v2.1.0+Rovo analysis and result loading ·v3.3.0+

Show site-wide metadata for a schema in a Confluence table.

Configure columns

Insert Metadata Report, choose an eligible schema and select the fields to display. The report enriches page, space and entity values for readable table cells.

Fixed and exposed filters

Fixed filters constrain the report configuration. Exposed filters let viewers refine results with typed controls, but only indexed schema fields are available.

Choose viewer controls and formatting

Enable search and filters, sorting, grouping, full screen, or CSV download for the published report. Choose comfortable or compact density and set header, row, border and group-row colors to fit the page.

Loading results

Reports load metadata incrementally. A report request can return up to 500 metadata records; use deliberate indexed filters to keep a large result set useful.

Arrange and format columns

In the report column editor, drag columns to change their order, rename headings, and disable columns that readers should not see. Add schema fields or page context as needed.

Open a column to set text effects, alignment, direction, width and optional header or cell colors. Report formatting also offers comfortable or compact density and colors for headers, alternating rows, borders and groups.

Analyze with Rovo

When Rovo is available on your site, enable Ask Rovo (AI analysis) in the report display settings. Save the macro and view the published page, then choose Ask Rovo to ask questions about the report. Analysis uses enabled columns and currently filtered, loaded rows; large reports may be truncated.

Load more results

Use Load more to include additional results. Search, sorting, grouping, CSV export and Rovo analysis apply to the loaded rows.

Build the report shape

Select an eligible schema, then add the schema fields and system context that readers need. Page title, space and last modified help people locate the source page; columns can be enabled, renamed, ordered and formatted for the report.

The macro is a site-wide view of saved metadata for its schema. It is not an editing surface: report interactions refine what a viewer sees without changing the schema or source documents.

Configure viewer controls

Enable the filter bar to expose search and filter interaction, sorting for table headings, and grouping when readers need collapsible sections. Full screen gives wide reports room; CSV downloads export the rows currently displayed after the active search or filters.

Use fixed filters to constrain the published report. Exposed typed filters are based on indexed fields, so configure indexing before relying on a filter for a review workflow.

Make dense data readable

Choose comfortable or compact density, then set a restrained palette for headers, odd rows, alternating rows, borders and grouping rows. Prefer concise enabled columns and focused filters because a single report request returns at most 500 metadata records.
