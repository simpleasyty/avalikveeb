Build a Metadata Report

Show site-wide entries for a schema in a Confluence table.

REPORTING

INTERACTIVE REPORTS

Give readers controls without changing the saved data.

Configure the report view around the schema fields and page context your audience needs.

Explore

Offer search, filters, sorting and optional grouping.

Focus

Open a larger view or choose compact density for dense reports.

Share

Offer CSV download and a small, deliberate color palette.

1

Configure columns

Insert Metadata Report, choose an eligible schema and select the fields to display. The report enriches page, space and entity values for readable table cells.

2

Fixed and exposed filters

Fixed filters constrain the report configuration. Exposed filters let viewers refine results with typed controls, but only indexed schema fields are available.

3

Choose viewer controls and formatting

Enable search and filters, sorting, grouping, full screen, or CSV download for the published report. Choose comfortable or compact density and set header, row, border and group-row colors to fit the page.

4

Loading results

Reports load entries incrementally. A report request can return up to 500 entries; use deliberate indexed filters to keep a large result set useful.

Build the report shape

Select an eligible schema, then add the schema fields and system context that readers need. Page title, space and last modified help people locate the source page; columns can be enabled, renamed, ordered and formatted for the report.

The macro is a site-wide view of saved entries for its schema. It is not an editing surface: report interactions refine what a viewer sees without changing the schema or source documents.

Configure viewer controls

Enable the filter bar to expose search and filter interaction, sorting for table headings, and grouping when readers need collapsible sections. Full screen gives wide reports room; CSV downloads export the rows currently displayed after the active search or filters.

Use fixed filters to constrain the published report. Exposed typed filters are based on indexed fields, so configure indexing before relying on a filter for a review workflow.

Make dense data readable

Choose comfortable or compact density, then set a restrained palette for headers, odd rows, alternating rows, borders and grouping rows. Prefer concise enabled columns and focused filters because a single report request returns at most 500 entries.

TIP

Viewer controls change the current report view. They do not rewrite the schema or the page entries.

Report boundaries

  • 1 Only indexed schema fields are available for configured report filters.
  • 2 A report request returns up to 500 entries; use focused filters for larger datasets.
  • 3 CSV downloads contain the rows currently displayed by the report.

Make an evidence review readable
