CONFIGURE COLUMNS

Grouping aggregation

v3.0.0+Mode ·v4.0.0+

Show a useful summary in each group row while keeping the individual rows underneath.

Add a group summary

Choose which column defines the group, then choose which column supplies the summary.

  1. 1

    Turn on Grouping

    Edit the Simple Table macro. In Display, enable Grouping.

  2. 2

    Create a group in the preview

    Click the group icon in a column header, such as Region. Click another header if you want a second grouping level.

  3. 3

    Choose the column to summarize

    Open Columns and select the column whose values you want to measure, such as Sales.

  4. 4

    Select Grouping aggregation

    In Aggregations, choose a function from Grouping aggregation. Check the preview, then save the macro.

Choose a summary

The menu changes with the selected column’s data type. None leaves that column without a group summary.

Column typeFunctionWhat appears in each group
Any typeCountNumber of rows in the group.
Any typeCount distinctNumber of different values in the selected column.
NumberSumTotal of the values, such as all sales in a region.
NumberAverageAverage value in the group.
NumberMinimum / MaximumSmallest or largest value in the group.
EnumValuesEach category with its count, such as Open (2), Done (1).
EnumModeMost frequent category with its count, such as Open (2).

See the result

Group these sales by Region and set Sales to Sum.

Source rows (Region / Sales)
North / 120 · North / 80 · South / 50
Grouped view
North: 120 + 80 = 200. South: 50.

The North group row shows 200; South shows 50. Expand North to see its original 120 and 80 rows.

What changes in the table

Each grouping level calculates its own summary. You can use different functions on different columns. A column that is neither grouped nor aggregated does not show a value in the group row. The original rows and values remain available when you expand the group.
