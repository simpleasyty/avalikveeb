Reorder columns

Put the most useful fields first without changing the source data or calculations.

COLUMNS

In the Columns tab, drag a column by its handle to the position you want. The preview updates immediately, so you can check the order as you work.

The chosen order is saved with the macro configuration and used in the published table. Data, calculations, and column types stay unchanged.

Change the column order

Drag a column row by its handle to the position where you want it to appear.

1

Open Columns

Edit the macro and switch to the Columns tab.

2

Grab the column handle

Find the column you want to move and drag the dotted handle on the left of its row.

3

Drop it in the new position

Drag the column up or down, then release it where you want it. The preview shows the new order immediately; save or publish the page when you are done.

TIP

Column order is a presentation choice. Put the information readers need to compare or act on first.

A simple example

A customer-success team reviews its list of active customers every week.

Before
Customer ID and internal notes appear before status, next review, and owner.
→
After
The team moves status, next review, and owner to the front. They can answer the most important questions at a glance.

Reorder Columns via Drag & Drop

Reorder columns directly from the Columns tab using drag and drop. Changes are reflected instantly in the table preview.

COLUMNS

How it works

  1. Edit the Simple Table macro or open the import dialog.
  2. Go to the Columns tab.
  3. Use the drag handle (⋮⋮) next to a column name.
  4. Drag it to the desired position.
  5. Review the updated order in the preview.
  6. Click Save to apply the change.

Working with many columns

Only one column settings panel can be open at a time. When you scroll through a long open panel, its compact column row remains sticky at the top of that panel so you can always see which column you are editing.

The sticky row stops at the next column, and it keeps the normal controls, icons, and drag handle available. You can close the panel, open a different column, or reorder columns without losing the current context.

Why it matters

Reordering columns helps you present data in a way that better fits your workflow, without modifying the underlying dataset or reimporting files.

Use case: Adjust column order for readability

Operations Team

Acme Corp — Platform Operations

Context and challenge:
Different users focus on different parts of the same dataset. Some prioritize status fields, while others care more about timestamps or ownership.

Solution – Column reordering:
Users rearrange columns in the configuration panel to bring the most relevant information to the front, without changing the underlying data.

Benefits:
• Better readability: highlight key information first.
• No data changes: adjust structure without touching the dataset.
• Quick updates: reorder columns in seconds.
• Flexible layouts: adapt the same table to different needs.

Impact:
Teams can quickly adapt table layouts, making data easier to scan and use across different contexts.
