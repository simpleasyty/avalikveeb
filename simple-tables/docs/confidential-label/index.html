Confidential label

Give sensitive tables an immediate, unmissable handling signal. The label appears above the table as a full-width confidential-content notice, before readers begin working with the rows.

DISPLAY

Put the signal where readers need it

Enable the label in Display settings, then pair it with your organization’s permissions and sharing guidance.

1

Open Display settings

Edit the macro and open Display in the table setup.

2

Open the Context group

Find Confidential in the Context group and turn it on.

3

Save the macro

Save or publish the page. Readers see a red confidential-content notice above the table.

4

Apply the page’s handling policy

Use the label with the appropriate sharing guidance and permissions for the page, space, and organization.

TIP

The label is most useful when it supports an existing handling policy: it tells authorized readers what they are looking at, rather than deciding who may see it.

A handling signal, not access control

The confidential label does not hide, encrypt, redact, or restrict table content. It does not alter Confluence permissions, exports, or sharing settings. Use Confluence permissions and your organization’s data-governance controls whenever access must be limited.

Example: mark a sensitive planning view

A planning team shares upcoming initiatives, budget ranges, and internal notes with its authorized members.

Scope access first
Use Confluence permissions so only the intended members can open the planning page. The confidential label does not replace that access control.
Mark the table clearly
Enable Confidential when the table contains sensitive initiatives, budget ranges, or internal notes. The full-width notice appears before the rows and establishes context before anyone starts working.
Make the handling policy clear
Pair the notice with your organization’s sharing and handling guidance. Authorized readers understand that the content needs care while the table remains fully usable.
Result
Permissions decide who may see the page; the label reminds those people how to handle its contents. It does not encrypt, hide, or redact any data.

RELATED RECOMMENDATIONS

Pair the signal with the right controls

Use Incognito mode and column visibility for table presentation, but use Confluence permissions for actual access decisions. Review export actions before enabling them for sensitive data.
