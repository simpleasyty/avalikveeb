CONFLUENCE TABLES

Native Confluence tables

v3.0.0+Interactive Action Items ·v6.9.0+In-page conversion ·v9.1.0+Guided draft publication ·v9.6.0+

Use Simple Table with Body for a Confluence table already on the page. It provides the same table capabilities as Simple Table; only the source and where you edit it are different.

See it in action

Public demo in English · No sign-in required

Try the live example (opens in a new tab)All demos → (opens in a new tab)

Make an existing table interactive

Keep editing the table where it was created. Sorting, search, filters, grouping, and the other table capabilities are the same as in the Simple Table macro.

  1. 1

    Wrap the native table

    Edit the Confluence page. Create or paste a native Confluence table. Select the table and insert the Simple Table with Body macro around it.

  2. 2

    Configure the interactive behavior

    Choose sorting, search, filters, and other table features. Preserve native appearance keeps Confluence formatting; Use first column as field names shows two-column tables as field and value pairs. Text fragments within one cell retain their own styles, such as bold or italic.

  3. 3

    Review the source and publish

    In the preview footer, switch between Simple Table for the final reader view and Confluence source for the native table stored in the macro body.

Good to know

The source preview is read-only. Edit the table in the Confluence page editor, then use macro preview or publish the page to confirm the final behavior.

Convert a table directly on its page

On a published page with an eligible native Confluence table of at least 21 total rows (including the header) still outside a macro, Simple Tables can show a conversion suggestion at the top. Tables already inside Simple Table with Body do not trigger the suggestion.

  1. 1

    Review the conversion

    Choose Preview conversion. Select a table to inspect, or Review all for all listed items. If the page also contains Page Properties Reports, one shared banner lists tables and reports together. Publish any pending changes using the steps below before confirming conversion.

  2. 2

    Confirm the conversion

    Simple Tables replaces the selected table in its current position with a Simple Table with Body macro. Rows, columns, cells and native formatting remain in the macro body. Converting several tables or a mixed selection of tables and reports publishes one new page version.

  3. 3

    Keep editing the table

    Afterwards, edit the native table inside the macro body in the page editor, or configure interactive table features in the macro settings.

Good to know

A draft identical to the published page does not block conversion. If the page or saved draft changes after review, the preview is rebuilt and you must review and confirm again. Canceling review does not publish anything.

Tip: Suggestions appear after confirming page-edit permission, your preferences and compatible content, and stay hidden in the editor. Not here opens two choices: Don’t suggest on this page hides all conversion suggestions for you on this page; Never suggest again turns off the currently shown suggestion types for you across this Confluence site. Other people are unaffected. Restore hidden pages or change type preferences in Apps → Simple Tables → Preferences; restoration keeps other preferences and the normal schedule. Administrators control the two site switches independently in Simple Tables → Settings. Native tables need at least 21 total rows, including the header; Page Properties Reports need at least 10 total rows, including the header (nine source pages). Both types share the schedule below. During waiting periods nothing is shown; open review remains usable.

Continue when a page has unpublished changes

The preview uses the latest saved draft, including pending title and content changes. Wait for Confluence to save changes in any open editor. Conversion stays unavailable until those changes are published.

  1. 1

    Publish in the Confluence editor

    Choose Open editor to publish. The editor opens in the same tab. Review all pending changes, including collaborators’ saved edits, then use Confluence’s Publish or Update button.

  2. 2

    Review the updated content and convert

    After publishing, check the page outside the editor. If the banner shows the initial suggestion, choose Preview conversion again. The review reloads current content and clears previous selections. Select the tables or reports again and confirm only after checking the updated preview. If pending edits still appear, use I've published, check again.

Two separate page versions

Publishing pending edits creates a page version; conversion creates another. Without a different draft, conversion publishes just one new page version.

If the result cannot be confirmed

If the save response is missing or the saved result cannot be verified, Reload page replaces the conversion action. Reload, check the converted content on the page, then choose Edit and check that the same content is there. Simple Tables does not automatically repeat publication.

Published pages. This banner workflow applies to published Confluence pages. Live Docs are excluded from conversion suggestions.

Suggestions become less frequent

If you see suggestions without opening a conversion preview, reminders gradually become less frequent. This schedule is shared by your account across all pages on this site.

  1. 1

    First active day

    Up to five appearances during the 24 hours after the first suggestion.

  2. 2

    Next active day

    Up to two appearances during the next active 24-hour period.

  3. 3

    Third active day

    One appearance, followed by a seven-day wait.

  4. 4

    Two weekly reminders

    One reminder after seven days, then another seven days later.

  5. 5

    Monthly reminders

    After the second weekly reminder, wait 30 days. Suggestions then appear at most once every 30 days.

You stay in control

Time away never skips stages: the next period starts only when another suggestion is shown. Opening a preview holds the current stage for one cycle without resetting its quota or shortening the wait. Not here can hide a page for you; restoring hidden pages does not reset the schedule. Previously saved timed pauses remain in effect until they expire. No banner or tab appears during waiting periods.

Which tables can trigger the banner?

Only tables still waiting to be converted

A page containing only Simple Table macros has no migration suggestion. If a native table remains, or a new one is added later, that table can be suggested. Existing migrated macros are not offered for conversion or repair.

Compatible tables at page level

Automatic suggestions cover standalone page-level tables with regular rows and cells and at least 21 total rows, including the header. Smaller tables remain available for manual macro insertion and stay out of banner review and bulk conversion. Tables inside layouts or other macros, merged cells, images, nested tables and unsupported macro content are not offered.

One banner for tables and reports

Eligible native tables and Page Properties Reports share the same review. You can convert each item separately or convert all eligible content together. Each report retains its own space and labels; when everything eligible is converted, the suggestion disappears.

Two-column detail tables

Some Confluence tables describe a page, project, request, or record. In this pattern, the first column is the field label and the second is its value.

For this kind of table, enable Display > Use first column as field names. This allows dates, statuses, numbers, and text to be handled appropriately for each field.

Action Items and permissions

Action Items remain interactive after publishing. Checkbox state, mentions, due dates, links, and inline formatting are preserved.

Viewers who can edit the page can complete or reopen tasks directly from the published table; others see an accessible read-only checkbox. Past due dates appear in red, and tasks remain independent even when multiple columns use the same visible heading.

Edit the table, check the result in preview

Changes to a native table may not appear immediately inside Simple Table with Body in the Confluence page editor. Check the interactive result in Settings preview or on the published page; the native table on the page remains the editing source.

Preview and known limitations

Check the interactive table in preview or after publishing. Some Confluence content displays differently, and some table arrangements cannot be nested.

Mentions

Mentions remain visible and can be highlighted for the current viewer, but they do not send native Confluence notifications from the macro-rendered table.

Dates

Confluence dates appear as localized date pills; the underlying value remains available for sorting, filtering, and calculations.

Nesting

Table Excerpt / Include works with the standard Simple Table macro. A table nested inside Simple Table with Body is not supported because of current Confluence Cloud limitations.
