Data residency

Simple Tables stores core table content alongside your Confluence content. Standard table workflows do not use a separate Simpleasyty database for processing or storing that content.

DATA STORAGE

Lifecycle, deletion, and recovery

Macro content and page attachments follow the lifecycle of the Confluence page that contains them. When a page is deleted, its associated Simple Tables content and attachments are deleted with it. Any recovery period is governed by the site’s Confluence recycle bin and retention configuration.

Residency scope

Simple Tables does not select an independent region or operate a separate data store for core table content. The data residency and retention controls configured for your Confluence site apply to the page content and attachments used by Simple Tables.

For a URL-based data source, the source system remains responsible for its own data location, access controls, and retention policy.
