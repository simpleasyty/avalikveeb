Full screen mode

Give readers a larger, focused workspace for the same table without making the Confluence page itself wider. It is ideal for dense reports, wide columns, and longer review sessions.

DISPLAY

Enable full screen for the right table

The embedded table remains the starting point. Full screen gives readers more room when they need it, without changing the page or the table configuration.

1

Open Display settings

Edit the macro and open Display in the table setup.

2

Find Viewer actions

In the Viewer actions group, enable Full screen. The option is off by default for new tables.

3

Save the macro

Save or publish the page. The table then shows an action that readers can use to open the larger view.

4

Review in a focused view

Readers open the full-screen action when they need more horizontal or vertical space, and return to the Confluence page afterwards.

TIP

Full screen is a viewer action, not a separate table or an export. Enable it when readers benefit from more space; keep it off when the embedded view is already easy to use.

What full screen changes—and what it does not

  • 1 It is an explicit Viewer actions setting and is disabled by default.
  • 2 It opens the existing table in a larger focused view; it does not create a new data source, duplicate the table, or change its saved configuration.
  • 3 Full screen adds room for inspection. It does not replace configuring column visibility, sizing, filtering, or sorting for the table itself.

Example: review a wide operations report

An operations table contains owner, status, region, dates, cost, and notes.

On the page
Keep a concise embedded table so the report, its context, and its decisions remain readable together. Readers can inspect the essential columns without leaving the page flow.
During investigation
Open full screen when owners, status, region, dates, cost, and notes need to be compared at once. Search, filters, and sorting remain available in the larger view.
Result
The page stays clear for a quick overview while detailed review gets the horizontal and vertical room it needs. The data source and saved table configuration remain the same.

RELATED RECOMMENDATIONS

Prepare the table before readers open it

Use Display settings to decide which controls accompany the table, and use column settings to make its wide view as clear as its embedded one.
