Hide columns

Keep the visible table focused without deleting data from the source or configuration.

COLUMNS

Hide a column in the Columns tab when it adds no value for the current audience. It disappears from the published table view.

The underlying data stays in place and you can show the column again at any time. Hiding simplifies presentation; use Incognito mode for editor-only content.

Hide a column

Change visibility directly in the settings for the column you want to remove from view.

1

Open Columns

Edit the macro and switch to the Columns tab.

2

Expand the column settings

Click the column that readers should not see to open its settings.

3

Turn visibility off

Under Column details, click the Visible button in Visibility. It changes to Hidden / Off and the preview updates immediately. Then save or publish the page.

TIP

Hide columns to reduce distraction, not to protect sensitive data. Use Confluence permissions when you need strict access control.

A simple example

An operations team publishes a weekly status report for stakeholders.

Before
The table shows internal IDs, technical check fields, and editing notes next to status and owner.
→
After
The team hides the internal fields. Readers see only status, owner, and next steps, while the data stays available for future editing.

Hide Columns

Hide columns you do not want to display while keeping the underlying data intact. Simple Tables lets you control column visibility directly from the table configuration.

COLUMNS

How to hide or show a column

  1. Edit the table macro or import dialog.
  2. Locate the column you want to hide in the table configuration.
  3. Use the visibility control to hide the column from the table view.
  4. Show it again at any time by re-enabling the same column.
  5. Click Save to apply the layout.

Why it matters

Hiding columns helps teams simplify tables and focus attention on the fields that matter most, without deleting any data. This is useful for stakeholder views, dashboards, and shared reports where not every field needs to remain visible.

Use case: Clean report views

Data Analyst

Acme Co — Business Intelligence

Context and challenge:
Reporting tables often include technical fields such as internal IDs, metadata, or helper columns that are useful for preparation but distracting in stakeholder-facing views.

Solution – Column visibility control:
Before publishing, the analyst hides non-essential columns so the table focuses on the most relevant business data. The hidden fields remain part of the dataset and can be shown again later if needed.

Benefits:
• Cleaner reports: present only the columns that matter to the audience.
• Less clutter: remove distracting technical fields from the visible view.
• Safe editing: hidden columns are not deleted from the dataset.
• Flexible presentation: adapt the same table for different readers or use cases.

Impact:
Teams can prepare clearer reports and dashboards without duplicating data or rebuilding the table in another tool.
