GETTING STARTED

Install Simple Tables

A Confluence administrator installs Simple Tables from Atlassian Marketplace for your site. Review the permissions and choose the right site before accepting the installation.

Prerequisites

To install Simple Tables, you will need administrator permissions in your Confluence Cloud instance. Please ensure you are logged in with an account that has these permissions.

START THE INSTALLATION

Open Simple Tables in Marketplace

Open Atlassian Marketplace, select Get it now, then complete the installation for your Confluence site.

View on Atlassian Marketplace

Complete the installation

Once you have opened the Marketplace listing, complete Atlassian’s standard installation flow.

  1. 1

    Click the Get it now button on the app listing.

  2. 2

    If you have multiple Atlassian Cloud instances, choose the instance where you want to install the app.

  3. 3

    Review the requested permissions and click Accept and install.

Good to know

Atlassian shows a confirmation when installation finishes. You can then add the Simple Table macro in Confluence.
