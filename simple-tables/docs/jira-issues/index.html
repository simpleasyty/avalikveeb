Jira IssuesVery soon

Turn a Jira search into a live, interactive table in Confluence. The integration is built, but it cannot be made available while Simple Tables is distributed as a free Marketplace app.

Why it is not available yet

The Jira integration is complete in Simple Tables, including the connection flow through Atlassian Administration. Atlassian’s Marketplace rules require the app to be paid before this cross-product Jira connection can be offered. Simple Tables is currently a free app, so the integration remains unavailable to customers.

How the planned source will work

This workflow is not available in the current free app.

  1. 1

    Connect Jira

    A Confluence administrator will manage the Jira connection in Atlassian Administration.

  2. 2

    Find issues

    Start with basic filters for project, assignee, issue type, status or text, or enter a JQL query. Choose a result limit from 25 to 1,000.

  3. 3

    Choose columns

    Select the Jira fields the table should display, such as key, summary, status, priority, assignee and dates. Check the preview before configuring the table.

  4. 4

    Publish a live view

    The saved query will run again when the table loads. Readers will see only issues their Jira access allows.

What the integration is ready to do

The connection and table options are implemented, but they are not available in the current free app. These are the features the integration is prepared to support once it can be offered.

Search

Start with a basic Jira search, or switch to advanced JQL when the worklist needs more precise logic.

Results

Choose from 25 to 1,000 issues and choose the columns that belong in the published table.

Connection

Use an administrator-managed Jira connection in Atlassian Administration. No Jira API token or separate Simple Tables app is needed.

Live data

Run the saved JQL again when the table loads, so the view can reflect the current Jira issues that each reader may access.
