Quick start

Simple Tables has two macros. Choose between them based on whether your table starts with data you import or connect, or with a native Confluence table that already exists on the page.

GETTING STARTED

Choose the macro for your starting point

Start with the Simple Table macro when your table begins with data or Confluence content. Choose Simple Table with Body when the native table already exists on the page.

Simple Table macro

Use the Simple Table macro when you want to paste data, import a CSV, JSON, or Excel file, use a page attachment, or connect content from Confluence.

It creates a configurable table with search, sorting, filters, grouping, column types, calculations, aggregations, and export. It is also the right macro for Page Properties, Confluence Content, and Table Excerpt / Include.

Simple Table with Body macro

Use the Simple Table with Body macro when a native Confluence table already exists directly on the page. The native table remains the editing source there, so there is no need to import or move its data.

The published macro adds the same interactive controls for readers while preserving supported content and formatting from the native table.
