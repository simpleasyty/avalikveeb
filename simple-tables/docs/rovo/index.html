Ask Rovo

Let readers open an Atlassian Rovo analysis of the table they are working with. It is a focused way to explore a filtered table, understand patterns, and ask follow-up questions without leaving Confluence.

CONTEXT

Prepare a focused analysis

Enable Ask Rovo only for tables where the capability and the context you share suit the workflow and your organization’s policies.

1

Confirm Rovo is available

Your Atlassian site and organization must have Rovo enabled. If it is unavailable or restricted by administrators, the action will not appear.

2

Enable Ask Rovo

Edit the macro, open Display, then turn on Ask Rovo in the Context group.

3

Prepare a useful view

Use filters to reduce the table to the question you want to investigate. Rovo receives the filtered rows and visible columns from the current table view.

4

Open the analysis

Select Ask Rovo in the table toolbar. Rovo opens with the serialized table context so the reader can begin analysis.

TIP

Ask Rovo is optional and availability is determined by the current Atlassian environment. A configured action appears only when Rovo is enabled and available for the site.

Use Rovo deliberately with table data

Ask Rovo serializes the filtered rows and visible columns of the current table view for the Rovo analysis. Before enabling it on sensitive tables, review your organization’s Rovo and data-governance policies, and use filtering and column visibility to prepare the intended context.

Availability and size limits

  • 1 Ask Rovo appears only when the table action is enabled and Rovo is available for the current Atlassian environment.
  • 2 Site or organization administrators can limit or disable Rovo. A missing action does not by itself indicate a Simple Tables issue.
  • 3 The serialized table context is capped at 30,000 characters. For large tables, filter to the relevant rows before opening the analysis.

Example: investigate delivery risk

An operations lead needs to understand why delivery work is slipping.

Focus the question
Filter the table to active delivery work and keep only owner, due date, status, and risk fields visible. The analysis now starts with the context needed to answer the actual question.
Review the context
Rovo receives the filtered rows and visible columns from the current view. Hide irrelevant or sensitive fields and account for the 30,000-character limit before opening the analysis.
Open Ask Rovo
Launch Rovo from the table action instead of manually copying rows into a separate prompt. The prepared table context is serialized to start the conversation.
Continue the investigation
Ask about repeated delays, outliers, ownership areas at risk, or items that deserve closer review. Verify important conclusions against the source data afterwards.

RELATED RECOMMENDATIONS

Prepare a better question

Filtering and column visibility help keep the analysis focused. For a reusable offline snapshot, use CSV or XLSX download instead.
