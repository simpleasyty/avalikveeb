Runs on Atlassian

Simple Tables works inside the Atlassian environment your team already uses for Confluence. It does not require a separate Simpleasyty server or external data platform.

TRUST & SECURITY

What is Runs on Atlassian?

Runs on Atlassian (ROA) is a trust badge for eligible Forge apps in the Atlassian Marketplace. It gives customers a quick way to identify apps whose compute and storage stay on Atlassian infrastructure and that meet Atlassian's requirements for data residency and controlled data egress.

THE THREE ROA REQUIREMENTS

A simpler way to understand where your app data goes.

The badge brings three infrastructure and data-handling signals together. For Simple Tables, they translate into the following boundaries.

Hosted by Atlassian

The app uses Atlassian-hosted compute and storage instead of a separate Simpleasyty backend.

More info →

Data residency

In-scope app data supports the same residency location as the host Confluence site.

More info →

Controlled data egress

External connections are restricted and visible to Atlassian controls. Simple Tables' core product flows do not send customer data to external services.

More info →

What the badge means in practice

Runs on Atlassian means Simple Tables is built and operated inside Atlassian's cloud platform, Forge. For your team, that means supported app data can stay in the Atlassian data region you select, while the core table workflow does not send customer data to an external Simpleasyty service.

The badge is useful context for a security review, but it is not an endorsement or support commitment from Atlassian. Simple Tables remains a third-party app developed by Simpleasyty, so you should still review its permissions, privacy information, and suitability for your organization. For the full detail, review Review Simple Tables security and privacy.
