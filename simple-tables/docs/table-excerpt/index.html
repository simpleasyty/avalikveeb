Table Excerpt / Table Excerpt Include

Simple Tables supports tables that are managed centrally with Table Excerpt and reused across Confluence pages with Table Excerpt Include. Teams can keep their established authoring structure while adding search, sorting, filtering, formatting, and aggregations to the included table.

REUSE TABLES

MAINTAIN ONCE, REUSE ACROSS PAGES

Reusable Confluence content becomes interactive.

The source table stays in its established location. Each included view can become easier to explore with Simple Tables, without maintaining a second copy of the data.

Central source

Maintain the source table once through the existing Table Excerpt workflow.

Multiple pages

Distribute the same table content across Confluence with Table Excerpt Include.

Interactive view

Add search, sorting, filtering, formatting, and aggregations for readers.

TIP

Recommended setup: Use the standard Simple Table macro for Table Excerpt workflows. Simple Table with Body is not currently suitable for this setup.

1

Maintain the source table

Create and update the table on its Confluence source page through your existing Table Excerpt workflow.

2

Reuse the table

Place the table on the destination page with Table Excerpt Include. The reused view remains connected to the same editorial source.

3

Add Simple Table

Use the standard Simple Table macro with the rendered table data and configure the interactive features you need.

4

Publish the result

Publish the page and verify search, sorting, filtering, formatting, and aggregations in the reader view.

Which Simple Tables macro should you use?

The macro choice depends on whether the table arrives as rendered reusable content or is edited directly inside the macro body.

Simple Table
Recommended and supported. It enhances the table data rendered through Table Excerpt Include.
Simple Table with Body
Not currently supported for this workflow because it would require a Confluence table to be nested inside the macro body.

Current limitations

  • 1 Confluence Cloud does not currently support the required table nesting inside Simple Table with Body reliably. Use the standard Simple Table macro instead.
  • 2 Continue editing the reusable data in the Table Excerpt source table. The included Simple Table view is not the editorial source.
  • 3 Verify the final interactive behavior in macro preview or on the published page.

When to use a native table instead

If the table lives on one page and should be edited directly there, use Simple Table with Body. That workflow keeps the native Confluence table as the editing source.
