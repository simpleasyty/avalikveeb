Table height

Choose how much of the table stays visible on the page before the table itself scrolls vertically.

FORMATTING

Table height limits only the visible area inside the macro. Your data, filters, sorting, calculations, and downloads stay unchanged.

Choose a smaller height when the Confluence page needs to stay compact. Choose Full content when every row should sit in the page flow without an internal height limit.

Four heights for four page contexts

Small · 5 → Medium · 10 → Large · 20 → Full content

Small, Medium, and Large create a visible area for roughly 5, 10, or 20 data rows. Full content removes that limit. If the table has fewer rows than the selected height, it simply shows the rows that exist.

This is not a pagination setting. Pagination and table height solve different space problems.

PresetGood for
SmallShort overviews, meeting notes, and compact pages
MediumDay-to-day lists and short reports
LargeBacklogs, registers, and active review
Full contentShowing a complete table directly in the page flow

Set the visible table height

Choose a height based on the page space available and how readers will use the table.

1

Open Formatting

Edit the macro and switch to the Formatting tab.

2

Choose Table height

Find the Table height control among the formatting options.

3

Select a preset

Choose Small, Medium, Large, or Full content. The selector description explains the view each preset creates.

4

Review with real data

Check the preview with a typical number of rows, then save or publish the page.

TIP

Full content shows every row without an internal height limit. For a long operational table, Large can offer a better balance between context and page length.

Example: keep a sprint backlog in view

A product team reviews a large sprint backlog on its Confluence page every week.

Before
With a small table area, reviewers continually scroll inside the macro even though they need to compare several tasks at a time.
→
With Large
The team chooses Large. Around 20 rows remain in the visible area, so priorities and owners are faster to compare without making the whole page overwhelming.

Use the page space well
